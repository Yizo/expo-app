## 系统栏是什么

**System bars（系统栏）**是屏幕边缘由操作系统控制的区域，用于显示时间、电量、通知，并提供系统导航。常见的有 Android / iOS 状态栏、Android Caption Bar、导航栏，以及 iOS Home Indicator。

内容如果绘制到了系统栏下面，文字和按钮就可能被挡住。尤其 Android 使用 edge-to-edge（边到边布局）时，应用内容可以延伸到状态栏和底部导航区域之下，页面必须配合安全区域设置 inset。

## 设置状态栏

`expo-status-bar` 提供 React 组件，可设置系统状态栏文字的浅色或深色样式。默认 Expo 模板用 `auto`，会随亮色 / 暗色主题切换：

```tsx
import { StatusBar } from 'expo-status-bar';

export default function RootLayout() {
  return (
    <>
      <StatusBar style="light" />
      {/* Stack 或页面布局 */}
    </>
  );
}
```

`style="light"` 表示状态栏使用浅色文字，通常适合深色背景。可以通过 `hidden` 属性控制可见性，也可以在运行时调用组件的静态方法：

```tsx
<StatusBar hidden />
```

```ts
import { StatusBar } from 'expo-status-bar';

StatusBar.setHidden(true, 'slide');
StatusBar.setStyle('dark', true);
```

Expo SDK 56 API 将 `StatusBar.setHidden` 和 `StatusBar.setStyle` 列为组件方法；旧的 `setStatusBarHidden` / `setStatusBarStyle` 别名已弃用。

## 设置 Android 导航栏

`expo-navigation-bar` 只控制 Android 底部系统导航栏。组件可以设定导航按钮样式，`hidden` 属性控制是否隐藏：

```tsx
import { NavigationBar } from 'expo-navigation-bar';

export default function RootLayout() {
  return (
    <>
      <NavigationBar style="dark" />
      {/* 页面布局 */}
    </>
  );
}
```

运行时也可以调用 v56 参考页列出的组件方法：

```ts
import { NavigationBar } from 'expo-navigation-bar';

NavigationBar.setHidden(true);
NavigationBar.setStyle('dark');
```

导航按钮颜色会受 Android 系统导航模式、`enforceContrast` 插件选项和 OS 版本影响；如果模拟器显示与预期不同，可以换成真实设备或不同版本模拟器检查。

## 关键名词

- **Status bar**：屏幕顶部显示系统信息的状态栏。
- **Navigation bar**：Android 屏幕底部系统导航区域；此处的 Expo 控制库是 Android 专用的。
- **Home Indicator**：iOS 屏幕底部的手势导航指示条。
- **Edge-to-edge**：应用内容铺到屏幕边缘，可能绘制在系统栏下方，需要 safe area inset 防遮挡。
- **安全区域**：避开刘海、状态栏、Home Indicator 等系统 UI 后仍适合放内容的区域；具体写法见[上一页安全区域](./017-安全区域.md)。
