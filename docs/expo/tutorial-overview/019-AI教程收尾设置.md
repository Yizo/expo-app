## 让状态栏在深色屏幕上可读

手机顶部会显示时间、电池和网络图标。如果 app 使用深色背景但状态栏仍是深色文字，就会看不清。教程让 agent 用 `expo-status-bar` 把所有 screens 的状态栏文字切换成浅色：

```text
页面背景是深色，但顶部时间、电池和信号图标也呈深色、不易阅读。
请使用 expo-status-bar 让所有 screens 的 status bar text 使用浅色样式。
```

状态栏是操作系统 UI 区域，不是普通网页 `<header>`；Expo component 帮 React Native 代码请求对应平台的系统栏样式。

## 配置图标与 Splash Screen

已下载资源包含 app icon 和 splash 图片。提示词将 app icon 指向 `assets/images/icon.png`，Splash 用 `assets/images/splash-icon.png`，并设置深色背景 `#25292e`，让图片在 Android / iOS / Web 加载时居中显示：

```text
将 app icon 设为 assets/images/icon.png。使用 expo-splash-screen config plugin
配置 splash screen：把 assets/images/splash-icon.png 放在 #25292e 深色背景的中央，
并为 Android、iOS 和 Web 使用相同视觉。
```

这些配置写在 Expo app config；与普通 JS 样式不同，需要重启开发服务器后重新加载：

```sh
# 在正在运行 Expo CLI 的终端按 Ctrl+C
npx expo start
```

重要限制：app 仍运行在 **Expo Go** 这个通用宿主 app 里，所以手机主屏幕上的图标仍是 Expo Go 图标；只有安装 standalone / development build 时，你自己的图标才会出现在系统主屏幕。

## 关键名词

- **Status bar**：OS 顶部包含时间、电量、网络状态的系统区域。
- **Splash screen**：React Native / JS app 载入前展示的原生启动画面。
- **Config plugin**：把 Expo app config 转成 Xcode / Gradle 工程修改的插件；配置变化需要重新生成 / 编译 native project。
- **Expo Go**：可运行项目 JS 的通用宿主客户端，它的 app icon 属于 Expo Go 自己。
- **Standalone / Development Build**：包含项目自身 bundle、图标和 native dependencies 的专属 binary。
- **Share sheet**：iOS / Android 提供的系统分享菜单。
