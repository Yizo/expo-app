## 手势组件与动画状态

本章给表情贴纸添加两种 native touch gesture：双击将 sticker 放大 / 缩回，拖动把它移动到图片不同位置。Gesture Handler 使用平台原生触摸系统识别 tap / pan；Reanimated 把共享状态转换成 UI 动画。

先把 Screen 放入 `GestureHandlerRootView`，并用 `Animated.Image` 替换一般图片：

```tsx
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import Animated from 'react-native-reanimated';

export default function Index() {
  return (
    <GestureHandlerRootView style={styles.container}>
      <Animated.Image source={sticker} style={styles.sticker} />
    </GestureHandlerRootView>
  );
}
```

## Double tap 缩放

`useSharedValue()` 建立可以在 Reanimated worklet / UI runtime 更新的动画值。`Gesture.Tap().numberOfTaps(2)` 配置双击，`onStart` 根据当前尺寸切换大 / 小，再使用 `withSpring` 得到弹簧过渡：

```tsx
const scale = useSharedValue(imageSize);

const doubleTap = Gesture.Tap()
  .numberOfTaps(2)
  .onStart(() => {
    scale.value = scale.value === imageSize * 2
      ? Math.round(scale.value / 2)
      : scale.value * 2;
  });

const imageStyle = useAnimatedStyle(() => ({
  width: withSpring(scale.value),
  height: withSpring(scale.value),
}));

<GestureDetector gesture={doubleTap}>
  <Animated.Image source={stickerSource} style={[styles.baseImage, imageStyle]} />
</GestureDetector>
```

`useAnimatedStyle()` 在 shared value 改变时更新 Native animated component 的 style；`withSpring()` 描述弹簧式目标过渡。

## Pan 拖动

用两个 shared values 记录横 / 纵偏移；pan 的 `onChange` 每次累加 event delta；`transform` 把偏移应用到外层 Animated.View：

```tsx
const translateX = useSharedValue(0);
const translateY = useSharedValue(0);

const drag = Gesture.Pan().onChange(event => {
  translateX.value += event.changeX;
  translateY.value += event.changeY;
});

const containerStyle = useAnimatedStyle(() => ({
  transform: [
    { translateX: translateX.value },
    { translateY: translateY.value },
  ],
}));

<GestureDetector gesture={drag}>
  <Animated.View style={[containerStyle, styles.stickerOffset]}>
    <GestureDetector gesture={doubleTap}>
      <Animated.Image source={stickerSource} style={[styles.baseImage, imageStyle]} />
    </GestureDetector>
  </Animated.View>
</GestureDetector>
```

外层 detector 处理 drag，内层 detector 处理 double tap；变换值和 scale 值分开存，避免移动手势改变缩放。

## 关键名词

- **GestureHandlerRootView**：Gesture Handler 的事件系统根容器，放在触摸交互树外层。
- **GestureDetector**：将手势对象绑定到一个可触摸的 React Native 组件。
- **Shared value**：Reanimated 动画状态，读取 / 修改时使用 `.value`。
- **Worklet / UI runtime**：Reanimated 将动画计算放在 UI 线程一侧运行的机制。
- **Pan delta**：指针每次移动产生的 X / Y 位移，累加后形成总偏移。
- **Spring animation**：模拟弹簧物理效果的动画方法。
