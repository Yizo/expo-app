## 在手机相册保存贴纸作品

本章要把显示中的照片和 emoji 合成一张可分享的图片。保存按钮不能截整张屏幕，只截照片与贴纸组合的区域；用户第一次保存时需要允许应用写入 / 添加照片，完成后显示确认提示。

给 agent 的改写提示词：

```text
在照片操作栏加入下载图标和 Save 按钮。点击后只截取照片预览区域，
连同贴在上面的 emoji 一起保存到手机照片库。使用 react-native-view-shot
捕获视图，使用 expo-media-library 写入相册；首次需要权限时再请求，
成功后弹出保存完成的提醒。不要把页面 header 和其它控件截进去。
```

源教程要求使用 `react-native-view-shot` 捕获合成区域，并由 `expo-media-library` 保存图片。实现时先确认 view-shot 的 target 是包住照片和 stickers 的容器 ref，而不是最外层整屏 view。

## Web 上另做保存分支

同一 Expo 项目也可在浏览器运行。源页说在 Expo CLI 终端按 **W** 打开 Web 版；手机使用的 `react-native-view-shot` 不支持 Web，所以 Save 要按平台分支处理：native 继续捕获原生 view，Web 用 `dom-to-image` 把对应 DOM 节点变成图片文件供浏览器下载。

交给 agent 的可选提示词：

```text
给 Web 版补上 Save。浏览器中不能用 react-native-view-shot；
请用 dom-to-image 捕获照片和贴纸组成的元素，并将图片下载为文件。
原生端仍使用已有 view-shot + media-library 保存方式。
```

这体现“共享业务 UI + 小段平台适配”的做法；分享路径不同，但最终都要选择同一个可视作品区域。Web 下载文件不会把图片写入手机相册。

## 关键名词

- **View Shot**：将 React Native 视图渲染结果捕获成图片文件的库。
- **`expo-media-library`**：与系统照片 / 媒体库交互并写入媒体文件的 Expo module。
- **Media permission**：应用向系统申请添加 / 读取用户照片的授权，必须由用户同意。
- **DOM capture**：在浏览器中把指定 DOM 元素转为图片；不能调用手机 native view API。
- **Platform branch**：使用 `Platform.OS` 或 `.web.tsx` / `.native.tsx` 文件为 Web 与原生端提供不同实现。

## 官方代码主题覆盖

源页没有可直接复制的 JavaScript 代码块，主要以 AI prompt 描述实现。本文重写了两个 prompt 的所有要求：操作栏增加 Save / 下载图标；仅捕获照片加贴纸的区域；native 用 `react-native-view-shot` 和 `expo-media-library` 保存、首次授权、成功 alert；终端按 W 打开 Web；Web 用 `dom-to-image` 捕获并下载；原生端继续使用 native 库。SDK56 安装版本边界已说明。
