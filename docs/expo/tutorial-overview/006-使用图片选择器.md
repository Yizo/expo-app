## 安装 Expo Image Picker

原生组件 `View` / `Text` 不能单独访问系统相册，需要 Expo SDK 的 `expo-image-picker`：

```sh
npx expo install expo-image-picker
npx expo start
```

教程在安装前停止运行中的开发服务器，安装后重新启动。也可将 `npx expo install` 替换为 `yarn expo install`、`pnpm expo install` 或 `bun expo install`。

## 调用系统媒体库

`launchImageLibraryAsync()` 打开设备原生图片 / 视频选择界面。以下示例只接受图片、允许用户编辑裁剪、保持较高压缩质量，并处理取消：

```ts
import * as ImagePicker from 'expo-image-picker';

async function pickImageAsync() {
  const result = await ImagePicker.launchImageLibraryAsync({
    mediaTypes: ['images'],
    allowsEditing: true,
    quality: 1,
  });

  if (result.canceled) {
    return undefined;
  }

  return result.assets[0]?.uri;
}
```

`result.canceled` 用于区别用户取消；成功时资产在 `result.assets` 数组里。Android / iOS 通常提供本地 `file://` URI，Web 可能返回 `data:` URI；其它元数据可能因平台缺省不同而是 `null`。

## 把按钮操作接到选择结果

将回调从画面传到可复用 Button 的 `onPress` prop：

```tsx
<Button theme="primary" label="Choose a photo" onPress={pickImageAsync} />
```

Button 内部把它传给 `Pressable`，可以让上层 screen 决定按下时运行什么功能：

```tsx
type ButtonProps = {
  label: string;
  onPress?: () => void;
};

function Button({ label, onPress }: ButtonProps) {
  return <Pressable onPress={onPress}><Text>{label}</Text></Pressable>;
}
```

用 `useState` 保存选择图片的 URI，然后以 `selectedImage` prop 交给 `ImageViewer`。静态 asset 与用户选择的 URI 是两种不同 source：

```tsx
const [selectedImage, setSelectedImage] = useState<string | undefined>();

async function pickImageAsync() {
  const result = await ImagePicker.launchImageLibraryAsync({
    mediaTypes: ['images'],
    allowsEditing: true,
    quality: 1,
  });
  if (!result.canceled) setSelectedImage(result.assets[0]?.uri);
}

function ImageViewer({
  imgSource,
  selectedImage,
}: {
  imgSource: ImageSourcePropType;
  selectedImage?: string;
}) {
  const source = selectedImage ? { uri: selectedImage } : imgSource;
  return <Image source={source} style={styles.image} />;
}
```

教程页也展示了成功返回的 Android、iOS、Web result 示例：均有 `assets`；原生项包含文件名、大小、宽高、MIME 与 URI，Web URI 示例是 data URL。消费时优先只依赖自己真正需要的字段，并处理字段可能为 `null` / 缺失的情况。

## 关键名词

- **Image Picker**：系统提供的照片 / 视频选择 UI。
- **Permission**：访问媒体库前操作系统向用户请求的授权；实际提示文案与 SDK 平台策略有关。
- **URI**：指向本地文件或 Web data URL 的资源位置字符串。
- **Optional chaining**：`assets[0]?.uri` 在空数组时安全返回 `undefined`。
- **Selected state**：React state 用于保存用户选择并触发 UI 重渲染。
