## 文件路由怎么映射

Expo Router 把 `src/app/` 里的路由文件转成 iOS / Android screen 和 Web 页面：

- `index.tsx` 对应所在目录首页；`src/app/index.tsx` 对应 `/`。
- `about.tsx` 对应 `/about`。
- `_layout.tsx` 声明共享 Stack、header 或 tabs，不直接变成路径。
- `(tabs)` 这类括号文件夹是 route group：用来组织共享布局，但不添加 URL 路径段。
- `+not-found.tsx` 捕获无法匹配的路径。

## 添加页面与 Stack

先建立一个普通 RN 页面：

```tsx
// src/app/about.tsx
import { StyleSheet, Text, View } from 'react-native';

export default function AboutScreen() {
  return (
    <View style={styles.container}>
      <Text style={styles.text}>About</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  text: { color: '#fff' },
});
```

根布局将页面注册到 Native Stack 并设置导航标题：

```tsx
// src/app/_layout.tsx
import { Stack } from 'expo-router';

export default function RootLayout() {
  return (
    <Stack>
      <Stack.Screen name="index" options={{ title: 'Home' }} />
      <Stack.Screen name="about" options={{ title: 'About' }} />
    </Stack>
  );
}
```

Stack 是屏幕堆栈：打开新页面时它压在上层，用户可以返回前一页。iOS / Android 的动画和返回手势由平台导航体验处理。

从页面用 Expo Router 的 `Link` 组件跳转：

```tsx
import { Link } from 'expo-router';
import { Button } from 'react-native';

<Link href="/about" style={{ color: '#fff', textDecorationLine: 'underline' }}>
  查看 About
</Link>
```

`href` 使用 URL 路径，而不是直接调用浏览器的 `history`。需要自定义 404 体验时加特殊路由 `+not-found.tsx`：

```tsx
import { Link, Stack } from 'expo-router';
import { View } from 'react-native';

export default function NotFoundScreen() {
  return (
    <>
      <Stack.Screen options={{ title: '找不到页面' }} />
      <View>
        <Link href="/">返回首页</Link>
      </View>
    </>
  );
}
```

## 添加底部 Tabs

把 `index.tsx`、`about.tsx` 和一个新的 `_layout.tsx` 移到 `(tabs)/`。根 Stack 再渲染 Tabs group：

```tsx
// src/app/_layout.tsx
import { Stack } from 'expo-router';

export default function RootLayout() {
  return <Stack><Stack.Screen name="(tabs)" options={{ headerShown: false }} /></Stack>;
}
```

在 `src/app/(tabs)/_layout.tsx` 定义底部导航：

```tsx
import { Tabs } from 'expo-router';

export default function TabLayout() {
  return (
    <Tabs>
      <Tabs.Screen name="index" options={{ title: 'Home' }} />
      <Tabs.Screen name="about" options={{ title: 'About' }} />
    </Tabs>
  );
}
```

页面还示范通过 `@expo/vector-icons` 添加 `Ionicons` 图标，并用 `tabBarActiveTintColor`、`headerStyle`、`headerTintColor`、`headerShadowVisible`、`tabBarStyle` 自定义导航栏颜色：

```tsx
import { Tabs } from 'expo-router';
import Ionicons from '@expo/vector-icons/Ionicons';

export default function TabLayout() {
  return (
    <Tabs screenOptions={{
      tabBarActiveTintColor: '#ffd33d',
      headerStyle: { backgroundColor: '#25292e' },
      headerTintColor: '#fff',
      headerShadowVisible: false,
      tabBarStyle: { backgroundColor: '#25292e' },
    }}>
      <Tabs.Screen name="index" options={{
        title: 'Home',
        tabBarIcon: ({ color, focused }) => (
          <Ionicons name={focused ? 'home-sharp' : 'home-outline'} color={color} size={24} />
        ),
      }} />
      <Tabs.Screen name="about" options={{
        title: 'About',
        tabBarIcon: ({ color, focused }) => (
          <Ionicons name={focused ? 'information-circle' : 'information-circle-outline'} color={color} size={24} />
        ),
      }} />
    </Tabs>
  );
}
```

教程在安装新依赖前先停止 Metro，安装后再启动：

```sh
npx expo install @expo/vector-icons
npx expo start
```

## 关键名词

- **File-based routing**：文件 / 文件夹位置决定 screen URL 的导航方式。
- **Stack**：压入新 screen 并支持返回上一层的导航结构。
- **Tab navigator**：并列主要页面的底部标签栏。
- **Route group**：括号目录只给路由共享布局和分组，不出现在路径名中。
- **Deep link**：使用 URL 直接进入 app 的特定路由。
