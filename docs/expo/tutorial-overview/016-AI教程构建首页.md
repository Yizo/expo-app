# 016｜Build with AI：构建首页

**翻页：**[上一页：AI 教程：创建第一个 app](./015-AI教程创建第一个Expo应用.md) · [目录](./README.md) · [下一页：Build with AI：添加贴纸](./017-AI教程添加贴纸.md)

**官方页面：**[Build with AI: Build the home screen](https://docs.expo.dev/tutorial/build-with-ai/build-the-home-screen/)

**版本边界：**当前 AI 教程要求 SDK57 模板并沿用匹配 SDK 的 Expo Go。项目 Expo 是 SDK56；添加 Expo 库时应通过 `npx expo install` 选择 SDK56 配套版本，不要把页面当成当前项目可直接复制的 SDK56 锁定实现。

## 1. 用 Expo Router 添加两个 Tab

教程第一步要求 agent 加入 **Home** 和 **About** 两个底部标签：Home 保留现有首页，About 暂时显示 About screen。使用 Expo Router 文件路由；背景、header 和 tab bar 用深色 `#25292e`，文字为白色，当前选中 tab 用黄色 `#ffd33d`，并加一枚适合含义的图标。

给 agent 的等价提示词：

```text
在 app 中增加 Home 和 About 两个底部 tabs，Home 显示现有主页，
About 暂时展示 “About screen”。用 Expo Router 路由，
将页面、headers 和 tab bar 设置为深色背景、白色文字，
选中标签用黄色。为 Home / About 添加 house 和 info-circle 图标。
```

在 Web React 中，路由通常由 react-router 或 Next 等提供；这里由 Router 从 `app/` 目录结构识别路由，再由 Tabs layout 把它们显示成平台导航。

## 2. 放置图片和装饰资源

Tutorial 用官方资源包中的占位照片和后续要用的 emoji 图片。agent 提示要求下载 Expo 文档资源 ZIP 并解压到 `assets/images`，重名文件需替换：

```text
下载 https://docs.expo.dev/static/images/tutorial/sticker-smash-assets.zip，
解压到 assets/images 并替换同名文件。然后用 expo-image 构建 Home：
将 background-image.png 大幅显示在屏幕中央，添加圆角；图片下方竖排两个按钮：
带黄色描边、白色底色、深色文字和图片小图标的 “Choose a photo”，
以及只有白色文字的 “Use this photo”。
```

agent 无法下载或解压时，可自行从官方资源链接保存、展开并复制到同一目录，然后再让 agent 只完成界面。该 ZIP 是 Expo 文档提供的项目素材。

## 3. 从相册选图

下一步通过 `expo-image-picker` 请求用户选择一张图片，并将其覆盖默认照片。选择取消时保留原本照片；首次打开系统相册时，系统可能先询问用户是否允许访问照片：

```text
添加 expo-image-picker。点 “Choose a photo” 后打开系统照片选择器；
成功选择时把选中的图片显示在原 placeholder 的位置。
用户取消时保持当前图片不变，不要清空 Home 内容。
```

这说明“打开图库”不是 Web 上直接读文件路径：应用要调用原生 photo picker，并根据用户的完成 / 取消结果更新 React state。若权限提示未出现或功能不可用，先确认设备 API、版本与平台权限设置。

## SDK56 的跟练方式

当前源页 prompt 指向最新模板；若在本地 Expo SDK56 跟练，先让 agent 检查已安装的 Expo Router、`expo-image` 和 `expo-image-picker` 版本，用 v56 官方文档对照相应 API。JS 层改动可由 Metro 更新；新增库若含原生代码，需放入 development build 并重新编译。

## 关键名词

- **Tab navigation**：同级主要页面的底部切换入口；每个 tab 对应一条 Router route。
- **Expo Router**：Expo 的文件系统路由方案；layout 文件描述同一导航层级的共享界面。
- **Asset pack**：图片等应用静态资源包，本例解压到项目的 `assets/images`。
- **Expo Image**：`expo-image` 图片组件；本章让它显示本地背景图。
- **Image picker**：`expo-image-picker` 原生图片选择接口，返回用户选中的图片 URI。
- **Cancel handling**：用户中止操作时保留当前界面和数据，避免覆盖成空值。

## 官方代码主题覆盖

源页没有可直接复制的 JavaScript / JSX 代码块；三个 agent prompt 与资源步骤都有改写示例：Expo Router Home / About tabs 和深色样式、图标语义、官方 ZIP 地址与 `assets/images` 布局、`background-image.png` 图片展示、按钮的两种视觉状态、`expo-image` 用途，以及 `expo-image-picker` 的权限 / 选择 / 取消保留行为。手动下载 ZIP 的备用步骤也已说明。
