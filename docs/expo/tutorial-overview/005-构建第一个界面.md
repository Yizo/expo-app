## 先把设计拆开

StickerSmash 首屏有一张居中的大图，底部有两个按钮。一个按钮会让用户选择照片，另一个按钮采用 app 预置的占位图。先把大图和按钮分别做成组件，可以让后续 modal / image picker 增加时保持文件职责清晰。

## 用 Expo Image 显示本地图片

模板自带 `expo-image`。它是跨平台图片组件，`source` 可以是静态资源或网络 URI：

```tsx
import { StyleSheet, View } from 'react-native';
import { Image } from 'expo-image';

const placeholder = require('@/assets/images/background-image.png');

export default function Index() {
  return (
    <View style={styles.container}>
      <Image source={placeholder} style={styles.image} />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#25292e', alignItems: 'center' },
  image: { width: 320, height: 440, borderRadius: 18 },
});
```

将图片逻辑移到 `src/components/image-viewer.tsx`，通过 prop 传入资源：

```tsx
import type { ImageSourcePropType } from 'react-native';
import { StyleSheet } from 'react-native';
import { Image } from 'expo-image';

export default function ImageViewer({ imgSource }: { imgSource: ImageSourcePropType }) {
  return <Image source={imgSource} style={styles.image} />;
}

const styles = StyleSheet.create({
  image: { width: 320, height: 440, borderRadius: 18 },
});
```

`@/components/image-viewer` 的 `@` 是模板配置的路径 alias；组件放在 `src/components`，不要放进 `src/app`，因为 `app/` 内文件默认参与路由。

## 用 Pressable 抽出通用按钮

`Pressable` 能响应点击、长按、按下 / 松开等触摸状态。Button 组件用 `label` prop 复用文案，用 `theme` 切换主要按钮样式：

```tsx
import { Pressable, StyleSheet, Text, View } from 'react-native';
import FontAwesome from '@expo/vector-icons/FontAwesome';

type ButtonProps = { label: string; theme?: 'primary'; onPress?: () => void };

export default function Button({ label, theme, onPress }: ButtonProps) {
  const primary = theme === 'primary';
  return (
    <View style={[styles.shell, primary && styles.primaryShell]}>
      <Pressable style={[styles.button, primary && styles.primaryButton]} onPress={onPress}>
        {primary && <FontAwesome name="picture-o" size={18} color="#25292e" />}
        <Text style={[styles.label, primary && styles.primaryLabel]}>{label}</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  shell: { width: 320, height: 68, padding: 3 },
  primaryShell: { borderWidth: 4, borderColor: '#ffd33d', borderRadius: 18 },
  button: { flex: 1, borderRadius: 10, alignItems: 'center', justifyContent: 'center' },
  primaryButton: { backgroundColor: '#fff', flexDirection: 'row', gap: 8 },
  label: { color: '#fff', fontSize: 16 },
  primaryLabel: { color: '#25292e' },
});
```

组件组合后让 `ImageViewer` 占用上方空间，两个按钮占下方三分之一：

```tsx
<View style={styles.container}>
  <View style={styles.imageContainer}>
    <ImageViewer imgSource={placeholder} />
  </View>
  <View style={styles.footerContainer}>
    <Button theme="primary" label="Choose a photo" />
    <Button label="Use this photo" />
  </View>
</View>
```

教程示范用 `tabBar` 样式、行方向 icon、以及 primary 的 inline style 覆盖默认样式。React Native `style` 通过对象或对象数组组合，不是直接写 CSS class。

## 关键名词

- **Static asset**：构建时已知的本地资源，可用 `require()` 让 Metro 收集。
- **ImageSourcePropType**：RN 图片来源的类型，用于静态模块或 URI 的 prop。
- **Pressable**：处理用户触摸交互的 RN 基础组件。
- **Reusable component**：用 props 把界面行为 / 外观抽取成可复用组件。
- **Path alias**：在 `tsconfig.json` 中配置的 import 简写路径。
