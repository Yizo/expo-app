# 014｜Build with AI：准备工具和 Expo 环境

**翻页：**[上一页：Build with AI 教程导言](./013-Build-with-AI教程导言.md) · [目录](./README.md) · [下一页：AI 创建第一个 app](./015-AI教程创建第一个Expo应用.md)

**官方页面：**[Set up your tools](https://docs.expo.dev/tutorial/build-with-ai/set-up-your-tools/)

**版本边界：**这是 Expo 当前 AI 教程。页面安装 Node.js LTS，不固定具体 SDK；本地 Expo SDK56 自身最低 Node 基线为 20.19.x。AI agent / plugin 命令只为说明该教程所需配置；本任务没有运行这些命令或连接任何服务。

## 准备项

- macOS / Windows / Linux 电脑；
- 一台与电脑在同一 Wi-Fi 的 Android / iOS 手机；
- AI coding agent 及其登录账号；
- 约 20 分钟安装环境。

AI agent 可以在终端工作，也可以在 Cursor 一类编辑器里操作；无论哪种模式，都需要终端来运行 Expo dev server。

## 安装 Agent 与 Node

Expo 页面把 Claude Code、Codex、Cursor 列为可选工具，并说明其它能编辑项目和运行命令的 agent 也可使用。示例安装方式包括：

```sh
# Expo 页面提供的 Claude Code install script 示例
curl -fsSL https://claude.ai/install.sh | bash

# Expo 页面提供的 Codex CLI install script 示例
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

Cursor 作为带 AI 面板的可视化编辑器安装。若已经有 agent，直接用现有工具即可。

Node.js 是 Expo CLI / Metro 运行所需的 JavaScript runtime。教程用 prompt 要求 agent 安装 LTS，并验证：

```text
请先说明计划做什么，然后检测我的操作系统并安装 Node.js LTS；完成后展示 node --version 和 npm --version 的输出，并告诉我是否要重开终端。
```

新终端中可查看版本：

```sh
node --version
npm --version
```

## 安装 Expo Go

手机从应用商店安装 Expo Go；在 Expo 网站创建账号，再让手机中的 Expo Go 与 CLI / agent tooling 使用同一 Expo 账号。这样 agent 修改 JS 后，手机可运行的开发客户端能快速载入更新。

## 给 Agent 安装 Expo Skills

Expo Skills 是教 agent 使用 Expo 工具、库与项目结构的指令文件。官方教程给出几类配置命令：

```sh
# Claude Code：在 Claude Code 内运行
/plugin install expo@claude-plugins-official

# Codex
codex plugin add expo@openai-curated

# Cursor
npx skills add expo/skills
```

使用 Cursor 时还要重开编辑器，并在 Skills 设置页确认技能载入。插件名在当前 Expo 文档中标为对应平台专用，选择命令要与所用 agent 匹配。

## 连接 Expo MCP Server

Expo MCP 服务器允许 agent 搜索官方文档和 EAS / workflow 信息。Claude Code 示例：

```sh
claude mcp add --transport http expo https://mcp.expo.dev/mcp
```

Codex 示例：

```sh
codex mcp add expo --url https://mcp.expo.dev/mcp
```

之后按 CLI 登录流程认证 Expo 账号。Cursor 在 UI 安装 MCP connection。还有本机截图 / 点击能力，但需要本地 simulator 与额外授权，本教程并未要求安装这部分能力。

## 测试安装

向 agent 提一个只需要读 Expo 官方文档的问题，检查它能否连上 MCP：

```text
请通过 Expo MCP Server 搜索官方文档中的 expo-image-picker，并用一句话说明它可以做什么。
```

如果无法查文档，回到 MCP 登录检查 CLI 是否完成账户认证。

## 关键名词

- **Node.js LTS**：长期维护版本的 JavaScript runtime；Expo CLI 使用它在本地运行。
- **Expo Go**：手机上的通用测试客户端，可载入 Expo 支持的项目 JS。
- **Expo Skill**：提供给 AI agent 的 Expo 项目指令和知识资源。
- **MCP Server**：向 AI agent 提供可调用工具 / 文档接口的协议服务。
- **Same account sign-in**：电脑与手机用同一 Expo 账号登录，便于扫码连接本机开发项目。
