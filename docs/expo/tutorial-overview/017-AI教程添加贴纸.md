## 让照片切换到装饰模式

用户从图库选出照片，或选择占位图后，界面从“挑选照片”变为“编辑作品”。本章给 agent 的要求可拆成以下 UI 状态：

1. 有照片时，隐藏初始的选图按钮。
2. 显示操作栏：左边 **Reset**，中间圆形 **+**。
3. 点加号，从屏幕底部滑出一个标题为 **Choose a sticker** 的 Modal。
4. Modal 从 `assets/images` 读取 emoji 图片，放进水平滚动列表。
5. 点中一个 emoji 后关闭 Modal，并把贴纸图层叠到照片上。

给 agent 的重写提示词：

```text
选好照片后，把“Choose a photo”和“Use this photo”按钮换成操作栏：
左侧 Reset 恢复最初的选图状态，中间的圆形加号打开底部弹出的
“Choose a sticker”对话框。对话框里横向滚动展示 assets/images 下的 emoji；
点一个 emoji 就关闭对话框，并把它作为覆盖层放在当前照片上。
```

可把状态理解成 React Web 里的条件渲染，但 Modal、手势和图片选择都调用手机平台能力。Reset 需要同时清理所选照片、贴纸与临时编辑状态，避免仅隐藏界面、实际数据仍残留。

## 拖动与双击缩放

第二步使用 `react-native-gesture-handler` 识别触摸，并使用 `react-native-reanimated` 在手势交互时更新贴纸位置和尺寸。可要求 agent 实现下面行为：

```text
让贴纸可交互：单指拖动时，贴纸跟随手指在照片区域移动；
双击时，在原大小与两倍大小之间切换。移动和缩放都要平滑，
不要在手指抬起时跳回原位置。请用 Gesture Handler 识别手势、
用 Reanimated 驱动动画，并保留照片 / Modal 的现有行为。
```

技术上可以把拖动理解成平移量 `{ x, y }`，把缩放理解成一个共享数值 `scale`；动画值更新不应让每一帧都触发整棵 React component tree 重渲染。贴纸移动区域需与背景图片的实际显示区域一致。

代码由 agent 生成后要在真机或模拟器上体验：只靠读代码无法判断手势是否迟滞、跳动、被父级滚动截走或放手后回弹。发现现象时描述步骤和结果，再让 agent 调整手势冲突 / 边界处理。

## 关键名词

- **Modal**：覆盖在当前 screen 上的一层临时 UI，本例从底部出现用于挑选贴纸。
- **条件渲染**：根据是否已选照片切换初始按钮和编辑工具栏。
- **Gesture Handler**：把触摸动作转换成 drag、double tap 等手势事件的原生交互库。
- **Reanimated**：在 UI 动画侧更新值，使持续拖动 / 缩放比每帧触发 React 更新更顺滑。
- **Transform / scale**：位置平移和缩放属于图层变换；它只改变贴纸呈现，不必重写贴纸源图片。
- **Gesture feedback loop**：开发者需要亲自感受实际交互，agent 无法替用户判断手势“手感”。

## 官方代码主题覆盖

源页没有直接的 React / TypeScript 代码块；两个 agent prompt 的功能要求均有等价重写：照片就绪后的 Reset / + 操作栏、底部滑出 Modal、emoji 横向列表和选中回调、关闭 Modal 并显示贴纸，以及 Gesture Handler drag + Reanimated 平滑位移、double tap 在原尺寸与两倍尺寸切换。SDK56 依赖选择注意事项已标明。
