# Expo / EAS 教程链

本模块从 [Overview of Expo and EAS tutorials](https://docs.expo.dev/tutorial/overview/) 开始，沿官方页脚 **Next** 继续记录页面。首页同时列出多个教程分支；本地目前跟随 Next 记录 Expo、Build with AI、EAS Tutorial，并在 EAS Tutorial 收尾页的 Next 处转入 CI/CD Tutorial。

## 版本说明

教程页面 URL 未固定 SDK 版本。本地项目为 Expo `~56.0.11`，完整原生 API 以 [SDK v56.0.0 官方参考](https://docs.expo.dev/versions/v56.0.0/)为准。若教程代码依赖 SDK 57 或较新的库 API，会在对应页注明差异；终端命令也需结合项目包管理器与 SDK 版本复核。
