## Learn 教程区

Learn 是 Expo 文档中的动手学习区。它包含从搭建工具开始的逐步教程，帮助读者在 iOS、Android、Web 上建立通用应用，并学习 Expo Application Services（EAS）。

首页列出四类学习路径：

1. **Expo tutorial**：自己写代码，从创建多平台 app 开始，覆盖路由、界面、图片、弹窗、手势、截图、平台差异和系统外观配置。当前页面把它作为 Next 链的下一步。
2. **Build with AI tutorial**：通过指挥 AI 编程代理搭建应用；面向没有编程经验的使用者。
3. **EAS tutorial**：学习 development build、多平台构建、内部测试、版本管理、production build 和预览分享。
4. **CI/CD tutorial**：用 EAS Workflows 自动化测试、构建和发布，包含 preview、生产部署、基于 tag 的发布和 Web 部署。

这些是不同教程分支；首页页脚 Next 明确进入普通 Expo tutorial 的 Introduction。本模块从那里跟进，不会仅因首页列出就把其它分支假装成同一条 Next 链。

## 学习方式

官方教程强调边做边学，每章以变化说明与代码片段带领读者从空项目完成一个跨平台贴纸应用 StickerSmash。教程概览页提供完整源代码链接和耗时预期，不含代码块；真正的实现代码从后续章节开始。

## 关键名词

- **Universal app**：一份项目代码支持 iOS、Android 和 Web 等多个目标平台。
- **Expo tutorial**：手动编码的逐章教程；跟随目录和文件变化可以理解界面、导航和原生 API 的组合。
- **EAS tutorial**：围绕云构建、更新和提交等 Expo 服务的学习路径。
- **CI/CD**：把代码变更后的检查、测试和交付流程自动化运行。
