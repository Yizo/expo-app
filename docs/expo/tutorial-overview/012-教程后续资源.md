## App 做完之后还能学什么

普通 Expo 教程完成后，页面推荐把学习分为三类：了解 Expo 项目工具与发布周期；巩固 React / React Native 核心能力；继续学习手势和动画。

### 把项目构建成应用

从机器上创建新项目可运行 `npx create-expo-app@latest`，再按顺序设置开发环境。后续值得了解：

- **Development tools**：CLI、设备、开发工作流和排错工具。
- **Development builds**：让自己的原生依赖进入调试 binary，并在设备 / Simulator 测试。
- **Development overview**：回顾 Expo 核心循环、JS 改动和原生构建的关系。
- **Expo Router**：从文件路由基础继续学习 Stack、Tabs、参数和认证。
- **App icon / splash screen / app config**：深入品牌、启动过程和原生配置字段。
- **App distribution / store submission**：内部分发、Release build、应用商店上传。
- **Debugging**：问题出现时使用设备工具、Dev Menu、React Native DevTools 等。

### 回头补 React 与 React Native

此 Tutorial 假设读者熟悉 React / TypeScript；若原生 UI 感觉陌生，Expo 页推荐继续学习 React hooks、`View` / `Text` 核心组件、平台差异、列表、Flexbox、宽高尺寸等基础。

### 手势和动画

StickerSmash 用 Gesture Handler 识别 double tap / pan，用 Reanimated 把 shared values 驱动到动画样式。后续可以单独深入触摸、手势冲突、动画时序与 UI thread 行为。

## Expo 社区

官方页面提供 Expo 社区讨论入口，供开发者提问和了解其他项目实践。排查具体 API / 版本时仍优先查 SDK 对应版本文档。

## 关键名词

- **Development build**：为当前 app 编译的调试客户端，包含该项目需要的 native modules。
- **App distribution**：将 dev / preview / release binary 交给团队、测试者或应用商店的流程。
- **Hooks**：React 管理 state、effect、context 等能力的 API 集合。
- **Gesture Handler**：将系统原生触摸 / 拖拽事件统一交给 React Native 回调的库。
- **React Native DevTools**：检查组件、日志、网络和 JS 性能的开发工具。
