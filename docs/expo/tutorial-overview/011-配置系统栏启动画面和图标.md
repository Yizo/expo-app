## 状态栏

模板预装 `expo-status-bar`，用 `StatusBar` 组件设置与背景相对的前景样式；例如深色背景上用白色图标：

```tsx
import { Stack } from 'expo-router';
import { StatusBar } from 'expo-status-bar';

export default function RootLayout() {
  return (
    <>
      <Stack>
        <Stack.Screen name={'(tabs)'} options={{ headerShown: false }} />
      </Stack>
      <StatusBar style={'light'} />
    </>
  );
}
```

Fragment 允许 RootLayout 同时返回导航和 StatusBar；状态栏 style 控制状态栏图标 / 文字前景，不是背景颜色。

## 应用图标

app icon 在主屏幕、应用管理列表和商店展示。教程模板内已有 `assets/images/icon.png`，尺寸为 1024 × 1024；EAS Build / 商店构建会生成对应设备所需规格。根 app config 字段指向源图：

```json
{
  "expo": {
    "icon": "./assets/images/icon.png"
  }
}
```

## Splash screen

启动画面是在 JS / React 页面准备完成前显示的原生启动界面。当前模板预装 `expo-splash-screen` config plugin，并把图片放在 `assets/images/splash-icon.png`：

```json
{
  "expo": {
    "plugins": [
      [
        "expo-splash-screen",
        { "image": "./assets/images/splash-icon.png" }
      ]
    ]
  }
}
```

更新 icon、splash 或 plugin config 后需要新的 native build。Expo Go 使用自己的宿主 app 启动画面；Development Build 的启动行为也不等于最终商店包，所以教程强调在 Preview / Production build 中验收 splash screen。

## 关键名词

- **Status bar**：iOS / Android 显示时间、网络与电量信息的系统状态栏。
- **App icon**：安装后在主屏幕 / 系统应用列表标识 app 的图标。
- **Splash screen**：React Native 页面准备好之前显示的原生启动画面。
- **Native build-time config**：写入二进制原生工程、需重新构建才生效的配置。
- **Config Plugin**：将 app config 值转换为 iOS / Android 原生设置的插件。
