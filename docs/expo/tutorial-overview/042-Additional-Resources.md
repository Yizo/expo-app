## 官方沟通与 GitHub 项目

官方沟通渠道：

- Expo Blog：版本发布、月度发布说明和其他 Expo 内容。
- Expo Changelog：EAS、Web Dashboard 与服务变更。

Expo GitHub 组织下常用仓库：

- expo/expo：Expo Go、SDK、文档与 Expo CLI。
- expo/eas-cli：构建、提交、发布更新所用命令行工具。
- expo/examples：与第三方 SDK / 服务集成的示例项目。
- expo/config-plugins：配置原生工程与第三方包的 config plugin。
- expo/snack：在浏览器中创建 / 运行 Expo 项目。
- expo/vscode-expo：VS Code Expo 工具扩展。
- expo/vscode-expo-theme：Expo 团队维护的 VS Code 主题。
- expo/fyi：Expo 工具与服务的排错指南。
- expo/orbit：桌面端启动 build 并管理模拟器的工具。

## 关键名词

- **Metro：**React Native 的 JavaScript bundler。
- **Hermes：**面向 React Native 应用的 JavaScript 引擎。
- **Config Plugin：**在 Expo prebuild 阶段修改或配置原生 iOS / Android 项目的代码工具。
- **HIG：**Apple Human Interface Guidelines，Apple 平台交互规范的官方指南。
- **Snack：**无需先搭本地原生工程即可试跑 Expo 代码的浏览器环境。
