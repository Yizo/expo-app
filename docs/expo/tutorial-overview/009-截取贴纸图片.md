## 安装截图和媒体库包

`react-native-view-shot` 将指定 native view 树捕获为图片文件；Expo `expo-media-library` 把图片保存到设备照片库。按当前 Expo SDK 安装：

```sh
npx expo install react-native-view-shot expo-media-library
```

图片库读写涉及用户敏感权限。教程用 `ImagePicker.useMediaLibraryPermissions()` 请求读取 / 写入媒体库权限；权限未 grant 时必须处理请求失败或用户拒绝：

```tsx
const [permissionResponse, requestPermission] =
  ImagePicker.useMediaLibraryPermissions();

useEffect(() => {
  if (!permissionResponse?.granted) requestPermission();
}, []);
```

## 给要截图的 View 建 Ref

只要将背景图与贴纸放在同一个 `<View>` 内，再用 `captureRef()` 捕获这个 View，就不会把整屏按钮也存进图片。`collapsable={false}` 要求 RN 保留实际原生 View 节点，以便原生截图 API 找到它：

```tsx
const imageRef = useRef<View>(null);

<View ref={imageRef} collapsable={false}>
  <ImageViewer imgSource={PlaceholderImage} selectedImage={selectedImage} />
  {pickedEmoji && <EmojiSticker imageSize={40} stickerSource={pickedEmoji} />}
</View>
```

## 捕获并保存

`captureRef()` 返回截图文件 URI。将该 URI 交给 `MediaLibrary.saveToLibraryAsync()`，并用 try/catch 处理磁盘或权限错误：

```tsx
async function onSaveImageAsync() {
  if (!imageRef.current) return;

  try {
    const localUri = await captureRef(imageRef, {
      height: 440,
      quality: 1,
    });
    await MediaLibrary.saveToLibraryAsync(localUri);
    alert('Saved!');
  } catch (error) {
    console.log(error);
  }
}
```

capture options 可控制尺寸与格式相关行为；本示例指定图像高度与质量。保存 media library 前权限弹窗由上一节请求。教程中的 `Save` button 调用此 async 函数。

## 关键名词

- **Ref**：组件实例 / native view 节点的引用，传给 capture 工具指定截图区域。
- **`collapsable={false}`**：防止 Android 优化掉只用于布局的 View 节点。
- **URI**：`captureRef` 输出图片文件位置，不是 base64 字符串。
- **Media Library permission**：系统授权 app 读取或保存用户照片的权限。
- **`captureRef`**：把指定 React Native View 渲染快照成图像文件。

## 官方代码主题覆盖

源页代码主题均有改写：两包安装命令、用 ImagePicker hook 申请读写权限、Ref 指向 image + emoji 子树、`collapsable={false}`、捕获尺寸 / quality、保存到 MediaLibrary，以及异步错误分支。示例只截取作品内容区域，不把操作 UI 混进图片。
