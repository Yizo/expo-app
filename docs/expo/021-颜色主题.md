## 亮色与暗色模式

移动设备系统允许用户选择 Light 或 Dark 外观。**Color scheme（颜色主题）**是操作系统当前使用的亮 / 暗外观偏好。应用可以跟随系统，也可以限制为固定主题。Expo 模板通常默认跟随系统。

## 配置应用支持的外观

在 `app.json` 设置 `userInterfaceStyle`：

```json
{
  "expo": {
    "userInterfaceStyle": "automatic"
  }
}
```

取值含义：

| 值 | 效果 |
| --- | --- |
| `automatic` | 跟随设备系统设置，并在用户切换时更新。 |
| `light` | 始终使用亮色主题。 |
| `dark` | 始终使用暗色主题。 |

缺省时应用使用 `light`。也能在 `android.userInterfaceStyle` 或 `ios.userInterfaceStyle` 单独覆盖平台值。Web 无需额外配置。

Android Development Build 需安装 `expo-system-ui`，否则 app config 设置会被忽略：

| 包管理器 | 命令 |
| --- | --- |
| npm / npx | `npx expo install expo-system-ui` |
| Yarn | `yarn expo install expo-system-ui` |
| pnpm | `pnpm expo install expo-system-ui` |
| Bun | `bun expo install expo-system-ui` |

未安装时终端会给出类似提示：

```text
android: userInterfaceStyle: Install expo-system-ui in your project to enable this feature.
```

可以用 Expo CLI 检查最终配置：

| 包管理器 | 命令 |
| --- | --- |
| npm / npx | `npx expo config --type introspect` |
| Yarn | `yarn expo config --type introspect` |
| pnpm | `pnpm expo config --type introspect` |
| Bun | `bun expo config --type introspect` |

## 已有 React Native 原生工程

Expo Prebuild / CNG 会根据 app config 写入原生设置。若项目维护自己的原生目录，则需在 Android 原生配置加入 `uiMode`，让 Activity 接收系统外观切换：

```xml
<activity android:configChanges="keyboard|keyboardHidden|orientation|screenSize|uiMode">
```

然后在 `MainActivity.java` 处理系统配置变更并向 RN 发送通知：

```java
import android.content.Intent;
import android.content.res.Configuration;

public class MainActivity extends ReactActivity {
  @Override
  public void onConfigurationChanged(Configuration newConfig) {
    super.onConfigurationChanged(newConfig);
    Intent intent = new Intent("onConfigurationChanged");
    intent.putExtra("newConfig", newConfig);
    sendBroadcast(intent);
  }
}
```

iOS 原生工程使用 `Info.plist` 的 `UIUserInterfaceStyle` 设置支持的外观；`Automatic` 表示同时跟随亮色和暗色系统设置：

```xml
<key>UIUserInterfaceStyle</key>
<string>Automatic</string>
```

## 在 React 组件中读取系统主题

使用 React Native 的 `useColorScheme` Hook 可以在渲染时读取当前模式：

```tsx
import { useColorScheme } from 'react-native';

function Greeting() {
  const colorScheme = useColorScheme();

  if (colorScheme === 'dark') {
    return <Text style={{ color: '#f3f3f3' }}>暗色界面</Text>;
  }
  return <Text style={{ color: '#242c40' }}>亮色界面</Text>;
}
```

不在组件中渲染时，`Appearance.getColorScheme()` 可以读取当前模式；`Appearance.addChangeListener()` 可监听主题变化。组件样式通常更适合 Hook，因为 Hook 会让 React 在主题变化时重新渲染。

## 一个完整的主题分支示例

React 组件可以根据 Hook 选择容器背景、文字颜色，并让 `StatusBar` 跟随系统：

```tsx
import { Text, StyleSheet, View, useColorScheme } from 'react-native';
import { StatusBar } from 'expo-status-bar';

export default function App() {
  const colorScheme = useColorScheme();
  const isLight = colorScheme === 'light';

  return (
    <View style={[styles.container, isLight ? styles.lightContainer : styles.darkContainer]}>
      <Text style={[styles.text, isLight ? styles.lightText : styles.darkText]}>
        当前系统主题：{colorScheme}
      </Text>
      <StatusBar />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, alignItems: 'center', justifyContent: 'center' },
  text: { fontSize: 20 },
  lightContainer: { backgroundColor: '#d0d0c0' },
  darkContainer: { backgroundColor: '#242c40' },
  lightText: { color: '#242c40' },
  darkText: { color: '#d0d0c0' },
});
```

## 在开发设备上切换主题

- Android Emulator 可用 `adb shell "cmd uimode night yes"` 开启暗色，`adb shell "cmd uimode night no"` 关闭。
- Android 真机或模拟器也可以在系统设置里切换深色模式。
- iOS Simulator 使用 `Cmd + Shift + A` 在亮色和暗色之间切换。

## 关键名词

- **`userInterfaceStyle`**：Expo app config 中设置的受支持系统外观策略。
- **`expo-system-ui`**：处理 React 树外系统 UI 的 Expo 模块；SDK 56 下需按版本兼容安装。
- **`useColorScheme`**：React Hook，读取系统外观并使界面响应变化。
- **`Appearance`**：React Native 外观接口；可主动读取当前主题或监听系统变化。
- **`Info.plist` / `AndroidManifest.xml`**：iOS / Android 原生应用的配置文件。
