## 静态资源是什么

静态资源是与项目代码一起管理、运行时需要的文件，例如图片、视频、声音、SQLite 数据库文件和字体。它与 JS 业务代码不同：资源可以在构建时嵌入应用原生 binary，也可以在运行时从本地或网络读取。

## 本地资源：直接导入文件

本地图片可以像 JavaScript 模块一样用 `require` 引用并传给 React Native `Image`：

```tsx
import { Image } from 'react-native';

export default function Photo() {
  return <Image source={require('./assets/images/example.png')} />;
}
```

Metro 能读取静态资源元数据并推导图像尺寸。Expo 的本地资源在开发中通过 HTTP 提供；正式构建时会自动打包进应用二进制。`expo-image`、`expo-file-system` 等库也能处理本地资源。

## 构建时嵌入资源：`expo-asset` 插件

如要将某些文件 / 目录在构建时链接进原生项目，可以用 `expo-asset` config plugin。按所用包管理器安装：

| 包管理器 | 命令 |
| --- | --- |
| npm / npx | `npx expo install expo-asset` |
| Yarn | `yarn expo install expo-asset` |
| pnpm | `pnpm expo install expo-asset` |
| Bun | `bun expo install expo-asset` |

在 `app.json` 声明项目根目录的资源路径：

```json
{
  "expo": {
    "plugins": [[
      "expo-asset",
      {
        "assets": ["./assets/images/example.png"]
      }
    ]]
  }
}
```

变更插件配置后要创建新的 Development Build。随后可以用资源名称加载，而不用在组件中 `require` / `import`。显式指定宽高，因为这种 URI 用法不能从 `require()` 读取尺寸：

```tsx
import { Image } from 'expo-image';

export default function HomeScreen() {
  return (
    <Image source={{ uri: 'example' }} style={{ width: 100, height: 100 }} />
  );
}
```

插件支持的资源格式以 Asset v56 参考页为准；不支持的格式可考虑运行时 `useAssets`。

## 运行时加载：`useAssets`

`useAssets` 会异步加载资源并缓存到本地，返回资源实例和错误状态。它适合必须运行时获取的情况，例如代码需要知道加载状态：

| 包管理器 | 命令 |
| --- | --- |
| npm / npx | `npx expo install expo-asset` |
| Yarn | `yarn expo install expo-asset` |
| pnpm | `pnpm expo install expo-asset` |
| Bun | `bun expo install expo-asset` |

```tsx
import { Image } from 'expo-image';
import { useAssets } from 'expo-asset';

export default function GalleryPreview() {
  const [assets, error] = useAssets([
    require('./assets/images/example-1.jpg'),
    require('./assets/images/example-2.png'),
  ]);

  if (error) return null;
  return assets ? <Image source={assets[0]} style={{ width: 100, height: 100 }} /> : null;
}
```

本地文件仍由打包器识别，但 Hook 会等资源可用后才返回其对象。

## 远程资源

网络图片不随 app 构建打包。直接把图片 URL 传给 `<Image>`；由于 Metro 无法读取服务器上的元数据，必须设置宽和高，否则默认尺寸可能是 0×0：

```tsx
import { Image } from 'expo-image';

export default function RemoteLogo() {
  return (
    <Image source={{ uri: 'https://example.com/logo.png' }} style={{ width: 50, height: 50 }} />
  );
}
```

远程文件在离线时可能无法访问，也可能被服务端移除；重要资源或离线流程应考虑随应用打包或缓存。

## 手动优化

- PNG 可尝试 `pngcrush`、`optipng` 等无损工具；无损压缩能在不改像素内容的前提下减小文件。
- 有损压缩会丢弃部分视觉信息来减少体积，可用 `imagemagick` 等工具配合相似度指标评估画质与文件大小。
- 视频、GIF、数据库等其它资源需要按资源类型自行优化。GIF 通常效率低，现代视频编码通常体积更小且画质更好。
- 字体文件的格式与加载方式见[上一页字体](./019-字体.md)。

## 关键名词

- **app binary**：编译后安装在设备上的 Android / iOS 应用文件。
- **静态资源**：构建前已存在于项目中的图片、字体等资源，不是 API 返回的运行时数据。
- **config plugin**：将声明写入原生工程、通常需要重新构建才能生效的配置扩展。
- **资源元数据**：例如图像宽高；`require()` 让打包器提前识别本地资源，远程 URL 则需要手动提供。
- **有损 / 无损压缩**：前者通过少量视觉变化换取更小文件；后者保留像素内容，仅优化文件编码。
