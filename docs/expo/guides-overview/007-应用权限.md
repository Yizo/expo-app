## 权限有构建时和运行时两步

读取位置、相机、联系人、媒体库等敏感设备数据前，app 要先向用户说明用途并请求权限。原生 build 还需要在构建时声明权限 / 用途文案；随后 JS 运行时再向系统弹出授权请求。

Expo Go 预先声明了一组通用权限，适合测试交互；独立 Standalone / Development Build 要把实际权限写进 app config 或库的 Config Plugin，并重新编译才能生效。修改 iOS `Info.plist` 的用途说明不能用 OTA 更新替代原生 build。

运行时询问的概念例子：

```ts
import * as MediaLibrary from 'expo-media-library';

const permission = await MediaLibrary.requestPermissionsAsync();
if (permission.granted) {
  // 用户授权后才读取媒体库
}
```

应用仍应处理拒绝、有限访问和再次进入设置的情况，不能假定用户一定会同意。

## Android 权限声明

SDK / 第三方库通常会自动把需要的权限加到 Android Manifest。若额外需要一个未自动添加的权限，可用 `android.permissions`；若依赖的 Manifest 过度声明权限，可以用 `android.blockedPermissions` 屏蔽：

```json
{
  "expo": {
    "android": {
      "permissions": ["android.permission.SCHEDULE_EXACT_ALARM"],
      "blockedPermissions": ["android.permission.RECORD_AUDIO"]
    }
  }
}
```

当依赖的库自身在 Manifest 添加权限时，`blockedPermissions` 是从合并结果中移除它的 Expo 配置方法。既有 RN 原生项目也可以在 Manifest 中用 `tools:node="remove"` 删除某项：

```xml
<manifest xmlns:tools="http://schemas.android.com/tools">
  <uses-permission
    android:name="android.permission.ACCESS_FINE_LOCATION"
    tools:node="remove" />
</manifest>
```

不需要的权限要审慎移除，调用对应原生功能时会导致失败。Android dangerous / signature 权限还涉及系统审批规则与 Play 审核。

## iOS 用途说明

iOS app 对相机、照片等数据访问要在 `Info.plist` 声明清楚给用户看的用途字符串：

```json
{
  "expo": {
    "ios": {
      "infoPlist": {
        "NSCameraUsageDescription": "用相机扫描活动入场券条码。"
      }
    }
  }
}
```

多数 Expo SDK 库会用 Config Plugin 提供默认文案，但 app 应改成准确反映产品行为的说明。媒体库插件还可设置照片读取、保存相关文案：

```json
{
  "expo": {
    "plugins": [[
      "expo-media-library",
      {
        "photosPermission": "允许应用选择要编辑的照片。",
        "savePhotosPermission": "允许应用把编辑后的图片保存到照片。"
      }
    ]]
  }
}
```

原生 RN 项目可直接在 Xcode 调整 `Info.plist`，借助自动补全填写合法 key。

## Web 与测试权限流程

浏览器通常只允许在 HTTPS 或 `localhost` 这类 **secure context** 下申请相机、定位权限。设备系统会限制在用户拒绝后重复弹窗；调试不同拒绝流程时，可能需要卸载并重装 native app。Expo Go 可通过开发服务器终端的 `I` / `A` 快捷键重新安装对应模拟器 / 设备客户端。

## 关键名词

- **Permission（权限）**：操作系统让用户决定 app 是否可访问设备数据或系统能力。
- **Usage description**：iOS 弹窗展示的用途说明字符串。
- **Manifest merge**：Gradle 把 app 与依赖的 `AndroidManifest.xml` 合并成最终构建清单。
- **Config Plugin**：Prebuild 时自动写入原生权限设置的扩展。
- **Secure context**：浏览器认为可安全调用摄像头、位置等 Web API 的上下文，通常要求 HTTPS 或 localhost。
