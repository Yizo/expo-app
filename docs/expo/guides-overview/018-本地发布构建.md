## Release binary 与签名

Release build 是准备分发的原生应用包。Android 的 Google Play 发布通常上传 Android App Bundle（`.aab`）；iOS 使用 Xcode 归档并上传 App Store Connect。仅在 JS 中改代码不能代替原生编译、签名和商店提交。

Android 需要 OpenJDK 的 `keytool` 和已生成的 `android/` 工程目录。若项目采用 Continuous Native Generation（CNG），先从 Expo 配置生成原生目录：

```sh
npx expo prebuild
```

已有 EAS Build 凭证时，可以通过 CLI 查看 Android credentials 并从 EAS 下载凭证；没有时可在本机创建上传密钥：

```sh
eas credentials -p android

keytool -genkey -v -keystore my-upload-key.keystore -alias my-key-alias -keyalg RSA -keysize 2048 -validity 10000
```

`keytool` 会要求设置密钥库密码，并生成 `my-upload-key.keystore`。EAS 下载的 credentials 可能包含 keystore 文件及对应的 store password、key alias、key password；将密钥文件放到 `android/app` 后，逐项确认密钥字段与 Gradle 属性映射一致。

## Gradle 属性和签名配置

在 `android/gradle.properties` 配置下列属性。真实密码应放在开发机用户级 `~/.gradle/gradle.properties`，避免随项目提交：

```properties
MYAPP_UPLOAD_STORE_FILE=my-upload-key.keystore
MYAPP_UPLOAD_KEY_ALIAS=my-key-alias
MYAPP_UPLOAD_STORE_PASSWORD=本机密钥库密码
MYAPP_UPLOAD_KEY_PASSWORD=本机密钥密码
```

`android/app/build.gradle` 的 Groovy 示例把这组属性应用到 Release signing config；原生模板已有 `android { ... }` 时，合并对应片段即可：

```groovy
android {
  signingConfigs {
    release {
      storeFile file(project.property('MYAPP_UPLOAD_STORE_FILE'))
      storePassword project.property('MYAPP_UPLOAD_STORE_PASSWORD')
      keyAlias project.property('MYAPP_UPLOAD_KEY_ALIAS')
      keyPassword project.property('MYAPP_UPLOAD_KEY_PASSWORD')
    }
  }

  buildTypes {
    release {
      signingConfig signingConfigs.release
    }
  }
}
```

接着在 Android 工程目录运行 Gradle release task：

```sh
cd android
./gradlew app:bundleRelease
# Windows 命令提示符可用：
gradlew.bat app:bundleRelease
```

输出 `app-release.aab` 位于 `android/app/build/outputs/bundle/release`。可手动上传 Google Play Console，或把已构建文件交给 EAS Submit：

```sh
eas submit --platform android --path ./app-release.aab
```

## iOS 发布

iOS 本机 Release 以 Xcode 完成签名和上传：先配置 Release scheme 和 Apple signing，再 Archive，并将归档上传 App Store Connect。具体步骤跟随 Xcode 版本以及项目的 Apple Developer 账号 / provisioning 配置；Expo Guide 的后续资源是完整手动提交流程。

## 关键名词

- **Keystore / upload key**：Android 签名材料。上传密钥用于证明发布者身份，私钥和密码必须保密并妥善备份。
- **Signing config**：Gradle 构建 Release variant 时从 keystore 读取签名信息的配置。
- **AAB**：Android App Bundle，交给 Google Play 后可按设备拆分生成安装包。
- **Archive**：Xcode 为某个签名配置产生的 iOS 发布归档。
- **CNG / Prebuild**：根据 Expo app config 与 config plugins 生成或重新生成 `android/`、`ios/` 原生工程。
