# Expo Guides 概览链

本模块从 [Guides: Overview](https://docs.expo.dev/guides/overview/) 开始，按每页页脚 **Next** 连续记录。内容来自 Expo 官方站，面向熟悉 React Web、刚接触 React Native / Expo 的读者。示例以解释概念为主，代码使用改写形式。

## SDK 版本说明

本地项目 Expo 版本为 `~56.0.11`。起点和 Guides 页面都未固定 SDK 版本；凡涉及 Expo 模块或可变 API 的代码，要结合 [SDK v56.0.0 官方参考](https://docs.expo.dev/versions/v56.0.0/)和项目安装版本确认。本索引记录官方当前页面的导航和内容，不能据此推定所有最新示例都兼容 SDK 56。
