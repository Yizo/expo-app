## Expo 对 React 开发者意味着什么

Expo 是建立在 React Native 之上的应用开发框架。React Native 提供用 JavaScript/TypeScript 编写界面和逻辑的能力；Expo 再提供项目初始化、文件路由、常用原生功能模块和开发、构建服务。它生成的是 Android/iOS 应用项目，不是把网页塞进手机浏览器。

Expo SDK 模块是访问设备能力的 JavaScript 接口，例如相机、位置、联系人和传感器。接口背后需要对应平台的原生实现。后续的开发构建会决定这些原生实现如何进入你自己的应用。

## 环境与版本

- 官方入门页要求安装 Node.js LTS。页面支持 macOS、Windows（PowerShell 或 WSL 2）和 Linux。
- SDK 56.0.0 参考页列出的最低 Node.js 版本是 **20.19.x**；本目录以此作为 v56 本地项目的最低 Node 基线。
- SDK 56.0.0 对应 React Native 0.85、React 19.2.3 和 React Native Web 0.21.0。Expo SDK 与 React Native 是版本配套关系，不能随意组合不同大版本。

## 用默认模板创建项目

`create-expo-app` 会生成可运行的项目骨架，并带有帮助入门的示例。官方支持以下包管理器写法：

```sh
# npm / npx
npx create-expo-app@latest my-app

# Yarn
yarn create expo-app my-app

# pnpm
pnpm create expo-app my-app

# Bun
bun create expo my-app
```

如果省略 `my-app`，交互过程会询问项目名称。不同模板可通过 `--template` 选择；通常先用默认模板学习项目结构，官方入门后续页面也按默认模板展开。

## 从官方示例开始

示例项目适合查看某项能力或集成的最小实现，例如路由、小组件或相机。下面第一组写法列出交互式选择，第二组按已知示例名创建：

```sh
# 交互式列出可选示例
npx create-expo-app@latest --example
yarn create expo-app --example
pnpm create expo-app --example
bun create expo --example

# 直接创建指定示例
npx create-expo-app@latest --example with-widgets
yarn create expo-app --example with-widgets
pnpm create expo-app --example with-widgets
bun create expo --example with-widgets
```

示例项目的文件组织可能和默认模板不同；页面导航、原生功能等概念仍可迁移理解。

## 可选：给 AI 编程代理配置 Expo 能力

项目模板可以包含供 AI 工具读取的项目约定。官方页面还提供了 Claude Code 与 Codex 的 Expo 插件 / Expo MCP 配置命令。它们属于可选工具配置，不是运行 Expo 应用的前置步骤。

```sh
# Claude Code
claude plugin install expo@claude-plugins-official
# 在 Claude Code 中使用 /mcp 完成 Expo 账号登录

# Codex
codex plugin add expo@openai-curated
codex mcp login expo
```

## 关键名词

| 名词 | 对 React 开发者的解释 |
| --- | --- |
| Expo SDK | 一组可由 JS/TS 调用的设备能力模块，以及相应的 Expo 工具链。 |
| 原生模块 | JavaScript API 与 iOS/Android 实现之间的接口；例如相机 API 最终调用系统相机能力。 |
| 模板 | 创建项目时预先生成的文件、配置和依赖集合。默认模板含入门示例；空白模板则更精简。 |
| 包管理器 | 负责安装 JavaScript 依赖的工具，如 npm、Yarn、pnpm、Bun；同一个项目通常选定一个并维护对应锁文件。 |
