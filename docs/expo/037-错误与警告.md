## Redbox 和 Yellowbox

Expo / React Native 开发时，React Native 的 LogBox 负责显示运行错误与警告。

- **Redbox error**：阻止应用继续运行的致命错误。
- **Yellowbox warning**：应用可能有问题的提醒，建议在发版前评估和处理。

项目代码也可以主动记录：

```ts
console.warn('这里有一个需要检查的问题');
console.error('发生错误');

// 未捕获的异常也会触发 Redbox
throw new Error('无法继续运行');
```

## 如何读 Stack Trace

Stack Trace（调用堆栈）是错误发生前一系列函数调用的位置记录。开发设备上和终端都会显示错误消息与堆栈。读堆栈时先找到首个项目源代码帧，再看行号、函数名和触发操作，通常比只看红色错误文本更容易定位问题。

例如，如果错误提到某个文件内访问了不存在的变量，就回到该文件对应行检查变量拼写、定义范围和异步加载状态。

## 继续排查

遇到错误可查官方运行时问题指南，也可以搜索 Expo 社区论坛、Expo / React Native GitHub Issues 或 Stack Overflow。提交问题时包含精简的错误、相关代码片段、SDK 版本和复现步骤。
