## Release Build 是什么

**Production Build（发布构建）**是准备提交到 Google Play 或 App Store 的 Android / iOS 原生应用包。它可以发到公开商店，也可先传 TestFlight 等商店测试轨道。

Expo 页面介绍了 EAS Build 云构建以及本机原生编译两条路。使用 EAS Build 时生产构建默认走应用商店格式：Android AAB、iOS IPA。生产构建通常不能像开发构建那样直接安装在任意模拟器上；Android 只有显式将 profile 的 buildType 设成 apk 才便于侧载，商店提交仍建议用默认 AAB。

## 用 EAS Build 构建

新项目在第一次 EAS Build 初始化时会生成 eas.json。Production profile 的基本形状如下：

~~~json
{
  "build": {
    "production": {}
  }
}
~~~

按平台构建或同时构建：

~~~sh
eas build --platform android
eas build --platform ios
eas build --platform all
~~~

可以通过 --message 给构建添加团队可见说明，例如：

~~~sh
eas build --platform ios --message "候选版本：检查地图页面"
~~~

## 商店开发者账号与签名

- 上传 Google Play 需要 Google Play Developer 账号。Expo 当前指南列出会员费为一次性 25 美元。
- 上传 Apple App Store 需要 Apple Developer Program 会员；Expo 当前指南列出年费 99 美元。
- EAS 可以协助创建和保存签名凭据。Android 可选择生成新 keystore 并由 EAS 安全保存；iOS 可登录 Apple Developer 账号，让 EAS 配置 distribution certificate 和 provisioning profile，也可手动提供。

## 监看构建进度

EAS CLI 默认等待构建结束。也可以中断等待并去 Dashboard 查看详情、构建日志；列出近期构建的命令是：

~~~sh
eas build:list
~~~

## 自动生成 Release Build

EAS Workflows 可在 main 分支每次提交后自动构建 Android / iOS：

~~~yaml
name: Create production builds

on:
  push:
    branches: ['main']

jobs:
  build_android:
    name: Build Android app
    type: build
    params:
      platform: android
      profile: production
  build_ios:
    name: Build iOS app
    type: build
    params:
      platform: ios
      profile: production
~~~

可以从 CLI 手动触发：

~~~sh
eas workflow:run create-builds.yml
~~~

## 本机构建发布版本

若不使用 EAS Build，可按 Android / iOS 原生发布流程本机构建。本机需要对应原生目录和工具链；CNG 项目先通过 Prebuild 生成目录，再按 Android Gradle / Xcode 官方步骤签名和归档。

Expo 页面特别说明，Android release AAB 构建应在 android/ 目录执行：

~~~sh
./gradlew app:bundleRelease
~~~

这个步骤代替旧 React Native CLI 指南中的 npx react-native build-android --mode=release。本机直接提交 IPA 则需要 macOS / Xcode；EAS 云端可从 Windows 或 Linux 发起 iOS 构建。

## 关键名词

- **AAB**：Android App Bundle，Google Play 常用发布上传格式。
- **IPA**：iOS App Store Archive，iOS 应用分发包。
- **EAS Build**：Expo 云构建服务，可使用构建 profile 管理平台选项与凭据。
- **签名凭据**：用于证明 app binary 属于开发者账号并允许设备 / 商店安装的证书、keystore 和 provisioning profile。
- **buildType: apk**：Android EAS profile 可生成可侧载 APK；商店发布仍建议 AAB。
