## 启动画面

**Splash screen（启动画面）**又称 launch screen，是用户打开应用后、应用准备好前短暂显示的原生首屏。它与 React 页面不同，在 JS 代码开始渲染前就由 iOS / Android 展示。

Expo 的 `expo-splash-screen` 原生 API 默认会在应用准备好时自动隐藏。其内置 config plugin 用于设定图片、背景色、深浅色模式等原生启动属性。

不要用 Expo Go 或 Development Build 作为最终启动画面验收环境：Expo Go 在等待时显示 app 图标，Development Build 还可能受 Expo Dev Client 自身启动画面影响。应用商店发布使用的界面应在 Preview 或 Production Build 验收。

### 准备素材与插件配置

官方建议启动图标使用 1024×1024、PNG、透明背景；默认路径为 `assets/images/splash-icon.png`。当前页面说明 Splash icon 只支持 PNG，若换成其它格式可能导致正式构建失败。

在 `app.json` 的 plugins 中配置 `expo-splash-screen`：

```json
{
  "expo": {
    "plugins": [
      [
        "expo-splash-screen",
        {
          "backgroundColor": "#232323",
          "image": "./assets/images/splash-icon.png",
          "dark": {
            "image": "./assets/images/splash-icon-dark.png",
            "backgroundColor": "#000000"
          },
          "imageWidth": 200
        }
      ]
    ]
  }
}
```

也可以按平台分别配置图像和背景色：

```json
{
  "expo": {
    "plugins": [
      [
        "expo-splash-screen",
        {
          "ios": {
            "backgroundColor": "#ffffff",
            "image": "./assets/images/splash-icon.png",
            "resizeMode": "cover"
          },
          "android": {
            "backgroundColor": "#0c7cff",
            "image": "./assets/images/splash-android-icon.png",
            "imageWidth": 150
          }
        }
      ]
    ]
  }
}
```

`resizeMode` 控制图片在容器内如何缩放，常用值包括 `contain`、`cover`。官方推荐用 config plugin；这些属性在构建出的原生二进制中生效，修改后需要重新构建。若项目不采用 Expo Prebuild / CNG，单改 `app.json` 不会改动已有原生目录，需要按原生方式手动配置。

### 旧版 iOS 缓存提示

官方页额外保留了一个 SDK 52 及更旧版本的 iOS 开发构建缓存排查方法。它不是 SDK 56 的常规命令，仅在那个旧版场景下运行：

```sh
npx expo run:ios --no-build-cache
yarn expo run:ios --no-build-cache
pnpm expo run:ios --no-build-cache
bun expo run:ios --no-build-cache
```

## 应用图标

应用图标会出现在手机主屏幕和应用商店。Expo 项目通常把 PNG 图放在 `assets/images/icon.png`，并在顶层 `icon` 字段指定路径：

```json
{
  "expo": {
    "icon": "./assets/images/icon.png"
  }
}
```

### Android Adaptive Icon

Android 自适应图标由前景图和背景颜色 / 图片组成，系统可以对其套用不同形状遮罩；Android 13+ 还能按设备壁纸主题生成单色图标。按需设置前景、单色、背景，以及旧版 Android 的备用单层图标：

```json
{
  "expo": {
    "android": {
      "adaptiveIcon": {
        "foregroundImage": "./assets/images/adaptive-foreground.png",
        "monochromeImage": "./assets/images/adaptive-monochrome.png",
        "backgroundColor": "#ffffff",
        "backgroundImage": "./assets/images/adaptive-background.png"
      },
      "icon": "./assets/images/android-legacy-icon.png"
    }
  }
}
```

前景和单色图使用 PNG；如果配置了背景图片，应与前景图尺寸相同。系统会自行裁切形状，不要预先在图像四角画圆角。

### iOS 图标

iOS 图标按 Apple 的图标规范设计。Expo SDK 54 起支持 Icon Composer 输出的 `.icon` 目录：

```json
{
  "expo": {
    "ios": {
      "icon": "./assets/app.icon"
    }
  }
}
```

Icon Composer 会处理深色外观，不必另提供 dark 版本。也可以沿用 PNG 图片方式：建议正方形、1024×1024，图案铺满画布、不带透明边角；新建 Expo 项目的 EAS Build 会生成其它所需尺寸。要为系统外观分别提供图标，可指定：

```json
{
  "expo": {
    "ios": {
      "icon": {
        "dark": "./assets/images/ios-dark.png",
        "light": "./assets/images/ios-light.png",
        "tinted": "./assets/images/ios-tinted.png"
      }
    }
  }
}
```

`ios.icon` 的外观变体会覆盖顶层通用 `icon` 设置。已有纯 React Native 工程若不使用 EAS Build，需要自行生成平台图标尺寸。

## 关键名词

- **Splash screen**：操作系统启动应用时显示的原生画面，不是 React 页面，也不能靠 Fast Refresh 改写。
- **Config plugin**：将 `app.json` 配置写入 Android / iOS 原生工程的插件。很多属性需要重建原生应用才生效。
- **CNG / Prebuild**：根据 Expo 应用配置生成原生项目的流程。
- **Adaptive Icon**：Android 前景 / 背景分层图标格式，便于系统按设备主题和遮罩形状渲染。
- **Preview / Production Build**：可真实体现用户安装包启动外观的构建类型，适合验收启动画面。
