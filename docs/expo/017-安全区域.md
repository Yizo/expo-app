## 什么是安全区域

手机屏幕不是整个矩形都能安全放内容：刘海、圆角、状态栏、手势 Home Indicator 等系统区域会遮挡边缘内容。**安全区域（safe area）**表示扣除这些遮挡后仍可放置交互内容的区域。

网页开发者可能习惯通过 `env(safe-area-inset-top)` 设置 CSS padding；React Native 常用 `react-native-safe-area-context`，它可以自动应用系统 inset，也能把数值交给组件自行布局。

## 安装

默认 Expo Router 模板通常已经安装了该库。其它模板可通过 Expo CLI 安装与 SDK 兼容的版本：

```sh
npx expo install react-native-safe-area-context
yarn expo install react-native-safe-area-context
pnpm expo install react-native-safe-area-context
bun expo install react-native-safe-area-context
```

## 方式一：`SafeAreaView`

`SafeAreaView` 是一个会把 safe area inset 作为额外 padding 应用到边缘的 View，适用于大多数页面。项目使用 Expo Router 默认模板时，通常可直接使用：

```tsx
import { Text } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';

export default function HomeScreen() {
  return (
    <SafeAreaView style={{ flex: 1 }}>
      <Text>内容位于安全区域内</Text>
    </SafeAreaView>
  );
}
```

若是其它模板且没有 Expo Router，要先在应用根节点放置 `SafeAreaProvider`：

```tsx
import { SafeAreaProvider } from 'react-native-safe-area-context';

export default function App() {
  return (
    <SafeAreaProvider>
      {/* 应用内容 */}
    </SafeAreaProvider>
  );
}
```

React Navigation 默认支持安全区域，并将 `react-native-safe-area-context` 作为同伴依赖。Web 也需要 `SafeAreaProvider`；如果使用服务端渲染，还要遵循库的 SSR 设置。

## 方式二：`useSafeAreaInsets`

需要精细控制各边距时，可以用 Hook 读取四个 inset，再加到自己的 View 样式中。官方最小结构相当于：

```tsx
import { Text, View } from 'react-native';
import {
  SafeAreaProvider,
  useSafeAreaInsets,
} from 'react-native-safe-area-context';

function HomeScreen() {
  const insets = useSafeAreaInsets();

  return (
    <View style={{ flex: 1, paddingTop: insets.top }}>
      <Text>安全区域顶部留白：{insets.top}</Text>
    </View>
  );
}

export default function App() {
  return (
    <SafeAreaProvider>
      <HomeScreen />
    </SafeAreaProvider>
  );
}
```

Hook 返回以下边缘尺寸（单位为 React Native 逻辑布局单位）：

```ts
{
  top: number;
  right: number;
  bottom: number;
  left: number;
}
```

一般页面先用 `SafeAreaView` 更直接；Hook 适合要把 inset 合入复杂滚动或自定义容器布局的场景。官方提示，设备旋转时 Hook 方案可能比 SafeAreaView 有更明显的布局更新开销。

## 关键名词

- **Inset**：某一边被系统遮挡或需要避开的距离数值。
- **`SafeAreaProvider`**：测量并向后代组件提供当前窗口安全区域信息的上下文提供者。
- **`SafeAreaView`**：按选定边自动增加安全区域内边距的 View。
- **`useSafeAreaInsets`**：直接读取 top / right / bottom / left 四个 inset 的 Hook。
- **逻辑像素**：RN 布局使用的单位；它不等于设备屏幕上的物理像素数。
