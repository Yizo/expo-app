## 继续学习的主题

Expo 官方界面开发分组在此页提供几个延伸入口：

- [TypeScript](https://docs.expo.dev/guides/typescript/)：配置 Expo TypeScript 项目，或把现有 JavaScript 项目迁移为 TypeScript。
- [Icons](https://docs.expo.dev/develop/user-interface/icons/)：选择矢量图标、自定义图标字体、图片图标和图标按钮。
- [ESLint 与 Prettier](https://docs.expo.dev/guides/using-eslint/)：设置代码检查与格式化。

本页本身是资源索引，没有代码块或命令示例。

## 关键名词与代码覆盖

- **TypeScript**：在 JavaScript 上增加静态类型检查的语言，能在开发阶段发现一部分类型错误。
- **矢量图标**：以路径描述图形的图标，放大时不容易变模糊；图标字体则把多个图形放进字体文件中。
- **ESLint**：检查 JavaScript / TypeScript 代码中常见问题和项目规则的工具。
- **Prettier**：按统一规则自动排版代码的格式化工具；它与 ESLint 的检查职责不同。

官方源页仅列出后续阅读链接，没有代码块、终端命令或配置片段，因此本页没有漏掉源页代码示例。
