## Expo SDK 是什么

Expo SDK 是一组可以单独安装的 JavaScript / TypeScript 包，用来访问相机、联系人、传感器、定位、通知等设备功能。安装一个 SDK 包后，应用代码导入它的模块；依赖原生代码的能力会进入原生构建，而不是浏览器 DOM API。

安装多个模块时，让当前 SDK 选择兼容版本：

```sh
npx expo install expo-camera expo-contacts expo-sensors
```

概念上的导入示意：

```tsx
import { CameraView } from 'expo-camera';
import { Contact } from 'expo-contacts';
import { Gyroscope } from 'expo-sensors';

// CameraView 是界面组件；联系人与陀螺仪 API 用来读取相应系统能力。
```

Latest 页在介绍例子里使用 `Contact.getAll()` 展示读取联系人；具体调用应以安装版本的 Contacts 文档为准。SDK 56 与 Latest 在 `expo-contacts` 等模块上的 API 可能不同，升级前需要对照 v56 页面。

## 既有 React Native 项目也可用 Expo SDK

Expo SDK 包不只适用于 `create-expo-app` 创建的工程；既有 React Native 工程也可以先安装并配置 `expo`，再逐项加入 SDK 包。Expo 当前文档列出的初始化方向包括：

```sh
# 新建使用 Expo SDK 的 React Native 项目
npx create-expo-app my-app --template bare-minimum

# 给现有 React Native CLI 项目加入 Expo Modules 基础设施
npx install-expo-modules
```

`bare-minimum` 是创建模板选项；它不表示“没有原生项目”，而是以最小原生壳为起点。给现有项目加 Expo 支持前，要确认其 RN 版本与目标 Expo SDK 配套。

## Beta 与 Canary

Expo SDK 稳定大版本之间会发布预发布包。**Beta** 是准备正式发布的候选版本；**Canary** 是从主分支截取的开发快照，包含代码日期和提交标识，可能有缺陷或包间不兼容。只有在愿意承担不稳定风险并测试后，才应使用它：

```sh
npm install expo@canary
npx expo install --fix
```

不要对日常 SDK 56 项目直接执行 Canary 升级；`--fix` 会调整依赖版本，应先检查变更并在单独分支 / 测试项目验证。

## 关键名词

- **Expo SDK package**：封装平台设备能力、并按 SDK / React Native 版本测试过的 npm 包。
- **原生模块**：JS 与 Android / iOS 系统代码之间的桥梁，用于暴露设备能力或原生 UI。
- **SDK 配套版本**：Expo SDK 绑定目标 RN、React 和工具链版本的发布组合。
- **预发布版本**：尚未作为稳定 SDK 正式发布的 Beta / Canary 包。
- **compile SDK / target SDK**：Android 编译时使用的 API 级别与应用声明面向的目标 API 级别。
