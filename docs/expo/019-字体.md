## 为什么打包自己的字体

Android 和 iOS 各自带有默认字体。自定义字体可以让应用在不同系统上保持一致的品牌视觉。SDK 56 的 [Font 参考页](https://docs.expo.dev/versions/v56.0.0/sdk/font/)说明 OTF / TTF 可用于 Android、iOS 和 Web；若同时有 OTF 与 TTF，通常优先 OTF，因为文件更小。Variable Font 的不同轴在平台间支持不一致，跨平台项目优先使用静态字重文件。

Google Fonts 中的字体也可通过 `@expo-google-fonts/*` 包安装。常见做法分两类：

1. 通过 **config plugin** 将字体编译进 Android / iOS 原生应用，启动时立即可用；需要新建 Development Build，不能在 Expo Go 中验证。
2. 通过 **`useFonts` Hook** 在运行时异步加载，适用于 Android、iOS、Web，也可在 Expo Go 中运行。

Web 使用运行时加载；`expo-font` config plugin 只对 iOS / Android 原生构建生效。

## 方式一：将本地字体编入原生应用

把字体放进项目，例如 `assets/fonts/`，再用当前 SDK 配套版本安装 `expo-font`。这些包管理器命令等价：

| 包管理器 | 命令 |
| --- | --- |
| npm / npx | `npx expo install expo-font` |
| Yarn | `yarn expo install expo-font` |
| pnpm | `pnpm expo install expo-font` |
| Bun | `bun expo install expo-font` |

在 `app.json` 配置插件。路径相对项目根目录；可以提供通用文件路径，也可以分别定义 Android / iOS 字体：

```json
{
  "expo": {
    "plugins": [[
      "expo-font",
      {
        "fonts": ["./assets/fonts/FiraSans-MediumItalic.ttf"],
        "android": {
          "fonts": [{
            "fontFamily": "Inter",
            "fontDefinitions": [
              { "path": "./assets/fonts/Inter-BoldItalic.ttf", "weight": 700, "style": "italic" },
              { "path": "./assets/fonts/Inter-Bold.ttf", "weight": 700 }
            ]
          }]
        },
        "ios": { "fonts": ["./assets/fonts/Inter-Bold.ttf", "./assets/fonts/Inter-BoldItalic.ttf"] }
      }
    ]]
  }
}
```

配置后要生成新的 Development Build。Android 的对象语法允许指定 `fontFamily`、`weight` 和 `style`；只填路径时 Android 通常以文件名作为字体族名。iOS 从字体文件内部读取字体族名。

组件中通过 `fontFamily` 选择字体：

```tsx
<Text style={{ fontFamily: 'Inter', fontWeight: '700' }}>Inter Bold</Text>
<Text style={{ fontFamily: 'Inter', fontWeight: '700', fontStyle: 'italic' }}>
  Inter Bold Italic
</Text>
<Text style={{ fontFamily: 'FiraSans-MediumItalic' }}>Fira Sans Medium Italic</Text>
```

若是已有原生 React Native 工程，Android 字体资源需放入 `android/app/src/main/assets/fonts`；iOS 则按 Apple 原生项目文档配置。

### 字体族名与 PostScript 名

文件名、设计师看到的字体名称、系统登记的字体族名可能不同。Android 路径写法通常以文件名（不含后缀）作为 `fontFamily`；iOS 从字体元数据取名称。PostScript name 是字体文件内供系统识别的唯一名称，例如 `Inter-Black`。

## 方式二：用 `useFonts` 在运行时加载

安装 `expo-font` 和 `expo-splash-screen`：

| 包管理器 | 命令 |
| --- | --- |
| npm / npx | `npx expo install expo-font expo-splash-screen` |
| Yarn | `yarn expo install expo-font expo-splash-screen` |
| pnpm | `pnpm expo install expo-font expo-splash-screen` |
| Bun | `bun expo install expo-font expo-splash-screen` |

在根布局加载字体。SplashScreen 在字体完成或发生错误之前保持显示，避免先出现系统默认字体再跳变；失败时也要结束等待：

```tsx
import { useEffect } from 'react';
import { Text } from 'react-native';
import { useFonts } from 'expo-font';
import * as SplashScreen from 'expo-splash-screen';

SplashScreen.preventAutoHideAsync();

export default function App() {
  const [loaded, error] = useFonts({
    'Inter-Black': require('./assets/fonts/Inter-Black.otf'),
  });

  useEffect(() => {
    if (loaded || error) SplashScreen.hideAsync();
  }, [loaded, error]);

  if (!loaded && !error) return null;
  return <Text style={{ fontFamily: 'Inter-Black' }}>Inter Black</Text>;
}
```

`useFonts` 返回 `[loaded, error]`。未就绪时维持启动等待，成功或失败后再渲染界面。字体就绪后通过 `<Text>` 的 `fontFamily` 选择它。

## 使用 Google Fonts

以 Inter Black 为例，config plugin 方式需安装 `expo-font` 和对应字体包：

| 包管理器 | 命令 |
| --- | --- |
| npm / npx | `npx expo install expo-font @expo-google-fonts/inter` |
| Yarn | `yarn expo install expo-font @expo-google-fonts/inter` |
| pnpm | `pnpm expo install expo-font @expo-google-fonts/inter` |
| Bun | `bun expo install expo-font @expo-google-fonts/inter` |

再把字体文件路径写进 app config；文件在 `node_modules` 中，因此路径仍是相对项目根目录：

```json
{
  "expo": {
    "plugins": [[
      "expo-font",
      {
        "fonts": ["node_modules/@expo-google-fonts/inter/900Black/Inter_900Black.ttf"]
      }
    ]]
  }
}
```

Android 可以使用文件名 `Inter_900Black`；iOS 使用字体元数据名 `Inter-Black`。需要同一段组件在两边工作时，可根据平台选择：

```tsx
import { Platform, Text } from 'react-native';

<Text style={{ fontFamily: Platform.select({ android: 'Inter_900Black', ios: 'Inter-Black' }) }}>
  Inter Black
</Text>
```

Google Fonts 也可以由 Hook 在运行时加载，安装字体包及 SplashScreen：

| 包管理器 | 命令 |
| --- | --- |
| npm / npx | `npx expo install @expo-google-fonts/inter expo-font expo-splash-screen` |
| Yarn | `yarn expo install @expo-google-fonts/inter expo-font expo-splash-screen` |
| pnpm | `pnpm expo install @expo-google-fonts/inter expo-font expo-splash-screen` |
| Bun | `bun expo install @expo-google-fonts/inter expo-font expo-splash-screen` |

字体包会导出可传给 Hook 的字体值；加载 / 错误处理与本地字体相同：

```tsx
import { Inter_900Black, useFonts } from '@expo-google-fonts/inter';

const [loaded, error] = useFonts({ Inter_900Black });
// 等 loaded 或 error 有值后隐藏 splash，再用 fontFamily="Inter_900Black" 渲染。
```

## 图标字体与远程字体

### 避免首次加载图标时空白

`@expo/vector-icons` 的字形文件第一次加载时，图标可能短暂不可见。可以在应用启动时预加载 Ionicons 字体：

```tsx
import Ionicons from '@expo/vector-icons/Ionicons';
import { useFonts } from 'expo-font';

const [iconsLoaded] = useFonts(Ionicons.font);
// 图标就绪后再渲染：
<Ionicons name="checkmark-circle" size={32} color="green" />
```

### 从网络加载

`useFonts` 的数据源也可以是 URL。Web 从远端字体站加载时，服务器必须正确设置 CORS；否则浏览器会阻止跨域字体。字体文件本地打包更可靠，也能离线使用。

```tsx
const [loaded, error] = useFonts({
  'Inter-SemiBoldItalic': 'https://example.com/fonts/Inter-SemiBoldItalic.otf',
});

if (!loaded && !error) return null;
return <Text style={{ fontFamily: 'Inter-SemiBoldItalic', fontSize: 30 }}>Inter SemiBold Italic</Text>;
```

## 平台默认字体与格式

- Android 默认字体是 Roboto；iOS 默认通常是 SF Pro。
- OTF / TTF 是官方支持的跨平台格式。`expo-font` config plugin 还支持 iOS 的 WOFF / WOFF2；跨平台项目优先 OTF / TTF。
- 其它格式需要扩展 Metro 静态资源配置；如果某平台无法渲染该格式，应用可能崩溃。
- 远程加载受网络和 CORS 影响；本地字体会随 app 安装，离线也能用。

## 关键名词

- **Config plugin**：将字体声明写入原生工程、随应用构建的方式，字体会包含在 app binary 中。
- **运行时加载**：应用启动后异步读取 / 下载字体，需要处理加载状态和失败情况。
- **PostScript name**：字体文件内部供系统识别的名称，可能和文件名不同。
- **字重 / style**：例如 700 粗体、italic 斜体；字体文件需实际提供相应字形。
- **CORS**：浏览器控制跨域资源读取的规则，远程字体服务器未正确配置时 Web 加载会失败。
