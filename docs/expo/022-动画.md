## 使用什么动画库

React Native 自带 `Animated` API，适合常见的属性过渡。Expo 项目也常用 **Reanimated** 实现更复杂的交互与动画；它提供共享值、动画函数和动画样式等 API，面向平滑、可组合、易维护的动画。

默认 Expo 模板已包含 Reanimated。其它项目按 SDK 匹配版本安装：

```sh
# Expo SDK 56 参考页要求安装 Reanimated 和 Worklets
npx expo install react-native-reanimated react-native-worklets
```

SDK 56 下，`babel-preset-expo` 会自动配置 Reanimated Babel 插件，通常不需再手动修改 Babel 配置。当前未版本化动画指南只显示 `npx expo install react-native-reanimated`；本项目采用 v56 时应按 v56 参考页同时安装 `react-native-worklets`。

## 最小示例：按按钮改变方块宽度

下面的例子使用共享数值驱动动画样式：按钮修改 `randomWidth.value`，Reanimated 用 500ms 缓动更新 `Animated.View` 宽度。

```tsx
import Animated, {
  Easing,
  useAnimatedStyle,
  useSharedValue,
  withTiming,
} from 'react-native-reanimated';
import { Button, StyleSheet, View } from 'react-native';

export default function WidthAnimation() {
  const width = useSharedValue(10);
  const animatedStyle = useAnimatedStyle(() => ({
    width: withTiming(width.value, {
      duration: 500,
      easing: Easing.bezier(0.5, 0.01, 0, 1),
    }),
  }));

  return (
    <View style={styles.container}>
      <Animated.View style={[styles.box, animatedStyle]} />
      <Button title="切换宽度" onPress={() => { width.value = Math.random() * 350; }} />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, alignItems: 'center', justifyContent: 'center' },
  box: { width: 100, height: 80, backgroundColor: 'black', margin: 30 },
});
```

## 关键名词

- **Shared value（共享值）**：动画运行时使用的可变值；此例中 `width.value` 决定方块宽度。
- **`withTiming`**：按指定时间和缓动曲线从当前值过渡到目标值。
- **`useAnimatedStyle`**：根据共享值生成与动画联动的样式。
- **Worklets**：Reanimated 用来在 UI 线程运行部分动画逻辑的函数机制；SDK 56 按 v56 文档一起安装 `react-native-worklets`。
- **Hermes / JS Inspector**：SDK 56 配套的 Reanimated 4 需要搭配 Worklets；Reanimated 调试应使用 Hermes 与 JavaScript Inspector，不能使用旧式 JavaScriptCore Remote JS Debugging。

## 其它方案

也可以使用 Moti 等动画库；官方页面说明 Moti 可用于 Android、iOS 与 Web。动画库要结合目标平台、项目依赖和交互复杂度选择。
