## 1. 启动开发服务器

在项目目录运行 Expo CLI。官方页面列出以下包管理器等价命令：

```sh
npx expo start
yarn expo start
pnpm expo start
bun expo start
```

Expo CLI 会显示二维码。扫描二维码可以在设备中打开项目；连着模拟器时，也可以在终端按 `A` 打开 Android Emulator，或按 `I` 打开 iOS Simulator。

## 2. 连接设备和网络

电脑和手机通常需要连接同一个 Wi-Fi，这样手机才能访问电脑上的开发服务器。如果网络路由器隔离了设备，或在公共 Wi-Fi 上连不上，可以改用 Tunnel 隧道连接：

```sh
npx expo start --tunnel
yarn expo start --tunnel
pnpm expo start --tunnel
bun expo start --tunnel
```

Tunnel 通过网络中转连接，兼容性通常更好，但页面重载会比本地 LAN / Local 连接慢。条件允许时优先使用本地网络或模拟器。

## 3. 修改屏幕并观察刷新

默认项目首页位于 `src/app/index.tsx`。可以先找到模板中的欢迎文案并改成自己的文字，例如：

```tsx
<ThemedText type="title" style={styles.title}>
  你好，Expo！
</ThemedText>
```

这是组件树里的文本子节点，样式仍由 `ThemedText` 和 `styles.title` 负责。修改 JS/TS 文件后，Expo Go 通常会自动刷新页面。

如果设备没看到改动，可以按顺序检查：

1. Expo CLI 是否处于 development mode。
2. 关闭手机上的应用再重新打开。
3. 摇动设备打开开发者菜单，或使用 `Cmd + D` 打开菜单。
4. 确认 Fast Refresh 已开启；如果菜单显示可启用 Fast Refresh，就切换它，然后再改一次文件。

**Fast Refresh（快速刷新）**会尽可能在保留运行状态的同时更新 React 组件。它更新的是 JavaScript/TypeScript 代码，不会把新的 iOS/Android 原生代码动态编译到已安装应用中。

## 默认项目的目录结构

当前页面列出的典型默认项目项如下。具体项目可以因为模板和 SDK 版本而不同：

```text
src/
  app/          Expo Router 路由文件和页面布局
  components/   可复用组件
  constants/    常量
  hooks/        自定义 React Hooks
assets/         图片、字体等静态资源
scripts/        项目脚本
app.json        Expo 应用配置
package.json    依赖和脚本
tsconfig.json   TypeScript 配置
```

React Web 的常见做法是显式注册路由表；Expo Router 使用文件结构约定路由。默认示例中的页面关系如下：

```text
src/app/index.tsx     → 首页路由 /
src/app/explore.tsx   → Explore 路由 /explore
src/app/_layout.tsx   → 页面共用的导航布局（此模板中配置标签导航）
```

`_layout.tsx` 不是普通页面，而是其所在目录路由的外壳，常用于放 Stack、Tabs、主题或其它共同配置。iOS/Android 上该模板的导航组件使用原生 tabs；Web 使用 Expo Router 的 Web tabs 实现。

## 默认模板提供的内容

官方页面列出默认模板包含文件路由、Android/iOS/Web 支持、图片展示、亮色与暗色模式，以及动画示例。它适合作为学习目录约定和运行方式的起点；业务应用通常会逐步替换演示页面。

## 关键名词

| 名词 | 解释 |
| --- | --- |
| Metro | React Native / Expo 使用的 JavaScript 打包工具。开发服务器负责把 JS/TS 模块打包给设备。 |
| 二维码 | 让 Expo Go 或自定义开发客户端找到电脑上开发服务器的连接入口；它不是把应用上传到商店。 |
| 文件路由 | 根据 `src/app` 下的文件名和目录生成页面地址的导航方式，类似框架依据文件约定建立路由。 |
| `_layout.tsx` | 路由目录的共享布局配置，通常定义页面之间的导航器。 |
| 原生 Tabs | 系统风格的标签导航，由 iOS/Android 平台组件承载；Web 端可以用单独的 Web 导航实现。 |
