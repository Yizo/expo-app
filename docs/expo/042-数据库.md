## 本机存储和云数据库的区别

本机 SQLite / SecureStore 等负责把数据保存在单个设备里；云数据库则把用户数据托管在远程服务中，可在设备之间同步，并由服务端处理共享访问。

本页是服务商和集成方式的导航索引，没有 API / SQL 代码示例。选择服务时，要结合项目是否已有后端、数据模型、实时同步、身份验证和团队运维方式。

## 官方列出的服务

| 服务 | Expo 文档摘要 | 适合进一步了解 |
| --- | --- | --- |
| [Convex](https://docs.expo.dev/guides/using-convex/) | TypeScript 数据库服务；官方介绍强调无需自行维护集群、SQL 或 ORM，并提供 WebSocket 实时更新。 | 需要响应式数据同步、并希望前后端使用 TypeScript 的应用。 |
| [Supabase](https://docs.expo.dev/guides/using-supabase/) | 托管 PostgreSQL 平台，还提供认证、文件存储、Edge Functions、实时同步、向量与 AI 工具。 | 希望以 PostgreSQL 为数据核心，同时使用托管认证和文件 / 实时能力的应用。 |
| [Firebase](https://docs.expo.dev/guides/using-firebase/) | Google 应用后端平台，提供实时数据库、云存储、认证、崩溃报告、分析等服务。 | 已使用 Google Firebase 生态，或需要这些云端服务组合的应用。 |

## 关键名词

- **云数据库**：托管在服务端的数据库，应用通常经网络 API 访问；数据可供多个设备或用户同步。
- **实时更新**：服务端数据变化后，客户端通过 WebSocket 等连接较快收到推送。
- **Hosted PostgreSQL**：供应商管理运行和备份的 PostgreSQL 数据库，不要求开发者自己部署服务器。
- **Edge Function**：运行在服务商边缘节点的服务端函数，常用于 API、Webhook 或对数据库操作的封装。
- **Local-first / 本机数据库**：优先在设备本地读写，可离线工作；与远程云端服务可以组合使用。
