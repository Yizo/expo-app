## EAS 提供什么

**Expo Application Services（EAS）**是服务 Expo 与 React Native 项目的托管云服务。开源 Expo 工具可免费使用；EAS 是可选服务，可以帮助团队把编译、上架、更新、网站部署和持续集成所需的服务器流程托管起来。

| 服务 | 用途 | 初学者理解 |
| --- | --- | --- |
| **EAS Build** | 在云端编译并签名 iOS / Android 原生应用 | 把 JS 与原生工程打包成可安装的 `.ipa` / `.aab` 等制品 |
| **EAS Submit** | 上传应用到 Google Play 或 Apple App Store | 自动化商店上传；不等于应用已审核通过或已发布 |
| **EAS Update** | 分发与原生版本兼容的 JS / 静态资源更新 | 可修复部分 JS 层问题；不能把新的原生模块“下载进”已安装二进制 |
| **EAS Workflows** | 运行 CI/CD 任务 | 自动串联测试、构建、预览和发布 |
| **EAS Hosting** | 部署 Expo Web 资源与 API Routes | 将导出的 Web 站点或路由处理函数托管起来 |
| **EAS Observe** | 查看线上性能指标 | 观察启动、交互、路由和更新等运行表现 |
| **EAS Metadata / Insights** | 商店资料管理或项目分析 | 官方页面标明为 Preview 的能力，成熟度和可用性可能变化 |

EAS 同时支持 Expo app 和其它 React Native 项目；采用 EAS 不要求把开源 Expo 全套功能都接入。反过来，使用 Expo CLI / SDK 也不强制使用 EAS，可以使用自己的构建和发布系统。

## 关键名词

- **Build / 二进制构建**：将 JS bundle、资源、原生模块和平台配置编译成安装包。
- **签名凭证**：iOS / Android 用来确认应用身份并允许安装或商店上传的证书、密钥等材料。
- **CI/CD**：持续集成与持续交付；代码变化后自动运行检查、构建和发布步骤。
- **OTA Update**：应用安装后从网络获取 JS 和资源更新；必须与二进制内的原生运行时兼容。
- **Preview**：预览阶段功能，行为、限制和服务级别可能继续调整。
