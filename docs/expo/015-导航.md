## 为什么 React Native 需要单独选择导航库

React Native 核心提供基础界面组件、触摸事件、网络和部分设备 API，但不内置完整的页面导航系统。Web React 开发者常直接使用 React Router；移动应用中的页面切换、原生返回手势、Tab / Stack 栏与深层链接由 React Native 导航库负责。

Expo / React Native 项目常见选择有 React Navigation 与 Expo Router。

## React Navigation

React Navigation 是组件式导航库：开发者在代码里组合 Stack、Tab、Drawer 等导航器，再接入应用自己的流程。它提供移动端平台风格、转场动画、手势、移动端与 Web 统一路由、深层链接和静态配置的类型化路由，并允许较自由地定制导航体验。

如果已有 React Native 项目或需要完全手动组织导航，可以从[React Navigation 入门文档](https://reactnavigation.org/docs/getting-started/)了解它。

## Expo Router：Expo 新项目推荐方案

Expo Router 是文件路由库。遵循 `app` 目录约定后，文件和目录会映射为页面路由；Expo CLI 和打包流程会自动集成，不需要先手动注册路由表。

它在基础文件路由上增加动态路由、类型化路由、开发时惰性打包、Web 静态渲染和自动深层链接。`create-expo-app` 新项目默认包含 Expo Router。

可把 Expo Router 理解为 React Native 上面的一层“文件约定 + 导航系统”：文件结构定义页面地址，布局文件组合原生 Stack / Tabs，通用 React 组件负责页面 UI。

## 关键名词

- **Stack**：后进先出的页面导航，类似移动端打开详情页再返回上一页的页面栈。
- **Tabs**：平级页面的标签导航。
- **Drawer**：从侧边滑出的抽屉导航。
- **深层链接**：从外部 URL / 系统入口直接打开应用中的某个页面。
- **类型化路由**：让 TypeScript 检查页面路径和参数，降低手写 URL 字符串时的错误。
- **文件路由**：由项目目录结构生成导航地址的路由方式。
