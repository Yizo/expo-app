## Expo CLI：项目开发的本地命令

Expo CLI 随 `expo` 包安装。通过 `npx` 调用本地 CLI，不需要安装一个全局旧版 `expo-cli`。常用命令如下：

| 命令 | 作用 |
| --- | --- |
| `npx expo start` | 启动 JS 开发服务器，可配 Expo Go 或 Development Build 使用。 |
| `npx expo prebuild` | 按 Expo 配置生成 iOS 与 Android 原生项目目录。 |
| `npx expo run:android` | 在本机编译并运行 Android 应用。 |
| `npx expo run:ios` | 在本机编译并运行 iOS 应用。 |
| `npx expo install package-name` | 安装与 Expo SDK 兼容的库；加 `--fix` 可修正指定依赖版本。 |
| `npx expo lint` | 初次可设置 ESLint；已配置后执行项目 Lint。 |

## EAS CLI：Expo 云端服务入口

EAS CLI 登录 Expo 账号，并管理 EAS Build、Update、Submit 等服务，例如云端开发 / 预览 / 正式构建、OTA 更新、证书和应用凭据。它与 `npx expo` 的职责不同：后者主要负责本地开发服务器和原生项目流程，EAS CLI 面向 Expo 云端服务。

安装 EAS CLI 的包管理器选项：

```sh
npm install --global eas-cli
yarn global add eas-cli
pnpm add --global eas-cli
bun add --global eas-cli
```

查看帮助：

```sh
eas --help
```

## Expo Doctor：检查项目健康状况

Expo Doctor 检查配置、`package.json`、依赖兼容性和项目整体状态，并在发现问题时给出说明或修复方向。它默认会参照 React Native Directory，并在项目有 `ios/`、`android/` 原生目录时检查应用配置是否同步。

官方支持通过以下方式在项目根目录运行：

```sh
npx expo-doctor
yarn dlx expo-doctor
pnpm dlx expo-doctor
bunx expo-doctor
```

```sh
npx expo-doctor --help
```

部分 Doctor 检查可以在项目 `package.json` 中配置，包括 React Native Directory 匹配检查和应用配置同步检查。

## Orbit：安装和启动构建

Expo Orbit 是 macOS、Windows 和 Linux 桌面工具，可安装并运行 EAS 构建、EAS 更新、Snack 项目，也可以从本地 `.apk`、iOS Simulator `.app` 或 ad hoc 签名包启动应用；它还可以显示 EAS 仪表盘中置顶的项目。

macOS 可经 Homebrew 安装：

```sh
brew install expo-orbit
```

Windows 和 Linux 版本从 Orbit 官方发布页下载安装；Linux 提供 Debian/Ubuntu `.deb` 与 Fedora/RHEL `.rpm` 包。Orbit 在各平台需要 Android SDK；macOS 上设备管理还依赖 Xcode 的 `xcrun`。

## Expo Tools for VS Code

这是 VS Code 扩展，为 `app.json`、EAS 配置、商店配置和 Expo Module 配置提供自动补全与 IntelliSense，也能用 VS Code 内置调试器设置断点、检查变量和在调试控制台执行表达式。

## Snack 与 Expo Go：快速试验

**Snack** 是浏览器中的 React Native 实验环境，无需本机安装开发工具即可编辑示例、选择 Android / iOS / Web 并看实时效果。一个最小屏幕通常使用 React Native 的组件：

```jsx
import { Text } from 'react-native';

export default function App() {
  return <Text>在 Snack 中试验</Text>;
}
```

**Expo Go** 是 Android / iOS 上的免费开源学习客户端。可通过手机安装，或用 `expo-go` 命令行工具按平台下载特定 SDK 对应的二进制文件、打印下载地址。官方命令分别适用于 npm、Yarn、pnpm、Bun：

| 包管理器 | 下载 Android Expo Go | 打印 iOS Expo Go 下载地址 |
| --- | --- | --- |
| npm / npx | `npx expo-go download android latest` | `npx expo-go url ios latest` |
| Yarn | `yarn dlx expo-go download android latest` | `yarn dlx expo-go url ios latest` |
| pnpm | `pnpm dlx expo-go download android latest` | `pnpm dlx expo-go url ios latest` |
| Bun | `bunx expo-go download android latest` | `bunx expo-go url ios latest` |

`latest` 可替换为指定 SDK 版本。下载的应用会写到当前目录，并在 `~/.expo` 缓存。该工具适用于 Android 设备、Android Emulator、iOS Simulator；受 Apple 侧载规则限制，不能用它把旧 Expo Go 版本侧载到真实 iPhone 上。Expo Go 仅适合学习与快速试验，生产应用应使用 Development Build。

如果项目 SDK 与 Expo Go 客户端不兼容，会看到“项目与此 Expo Go 版本不兼容”一类错误。解决方式取决于 Android 设备、真实 iOS 设备或模拟器，按官方版本不匹配排查指南处理，或把项目升级到受支持的 SDK。

## React Native Directory：查找第三方库

适用于 React Native 的第三方库通常也能在 Expo 项目中使用；包含原生代码的库通常需要 Development Build。本页推荐通过 React Native Directory 搜索 Expo SDK 未收录的库，并检查其平台支持、维护状况和兼容性。

## 关键名词

- **Expo CLI**：本地开发和构建命令集合，`expo` 项目依赖安装后即可用 `npx expo ...` 调用。
- **EAS CLI**：Expo 云服务命令行，用于云构建、提交和更新等。
- **Prebuild**：根据 Expo 配置生成原生项目代码；它是连续原生生成流程的一部分。
- **Expo Doctor**：检查 Expo 项目配置和依赖的诊断工具。
- **Snack**：浏览器内运行和分享的 RN 小实验，不要求先准备本机原生工具链。
- **Expo Go**：Expo 提供的通用测试客户端；能力取决于该二进制中已编译的原生模块。
- **Development Build**：为自己的应用编译的调试客户端，可包含 Expo Go 没有的原生库。
