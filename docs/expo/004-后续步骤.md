## 可选：重置默认示例

如果想从干净页面开始，默认模板提供 `reset-project` 脚本。不同包管理器的调用方式是：

```sh
npm run reset-project
yarn run reset-project
pnpm run reset-project
bun run reset-project
```

官方页面说明，该脚本会把原有 `app` 示例目录移动为 `app-example`，再创建一个新的 `app` 目录并写入 `index.tsx`。这一步清理的是模板页面，执行前应先确认自己的修改已经保存。

## 从练习项目走向完整应用

官方推荐继续按应用生命周期学习：

1. **Develop**：构建界面、导航和业务流程，学习权限、原生模块、数据库等主题。
2. **Review**：把应用预览分享给同事或测试者收集反馈。
3. **Build / Submit**：生成 Android/iOS 发布构建并提交到应用商店。

这些步骤不是把网站直接部署到商店。React Native 代码需要进入平台原生构建流程；Expo 可以提供相应工具和服务来管理该流程。

官方还推荐跟随[端到端 Expo 教程](https://docs.expo.dev/tutorial/introduction/)一步步完成通用应用练习。

## 关键名词

- **Review / 预览分发**：将特定构建或更新发给团队审阅，不等于公开上架。
- **发布构建**：面向真实用户的 Android 或 iOS 原生应用产物。
- **Submit**：将发布构建及其商店元数据提交给 Apple App Store 或 Google Play 审核；提交不代表已通过审核。
- **EAS**：Expo Application Services，Expo 的构建、更新、提交等云服务集合。是否使用云端服务取决于项目流程；本页只引导至后续指南，没有要求现在配置。
