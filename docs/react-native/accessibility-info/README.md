## 遍历起止与边界

实际链首为 AccessibilityInfo，按 footer Next 穿过 APIs、Globals、Hooks、Android APIs，再进入 iOS APIs，终点为 Settings。当前连续前缀共 **76 页**；Settings footer 没有 Next，因此本次到达官方链终点。侧栏未被 Next 到达的其它链接不纳入此单链。

每个编号页顶部和底部都有上一页/目录/下一页相对导航。Settings 为末页，明确标注无后续页面并返回目录。

## 代码覆盖说明

每页均包含“源页代码覆盖”或“代码覆盖清单”。有代码主题的页面以中文说明和重写示例覆盖，例如 Animated、AppRegistry、Linking、PerformanceObserver、PermissionsAndroid 和 ActionSheetIOS。仅一两句 WIP 类型页明确记录官方当前文档未提供示例或 API 细节，不以外部资料补充。部分支持和实验 API 在对应页单独标注。
