## 开发环境守卫

**__DEV__** 是 RN 提供的开发环境伪全局，可包裹仅在开发模式运行的代码。编译时它会被内联；在 minified production build 中，__DEV__ 为 false 的分支会被整体移除。

    if (__DEV__) {
      DevSettings.addMenuItem('调试页面', openDebugScreen);
    }

    if (!__DEV__) {
      return null;
    }

它适合保护调试入口或开发诊断逻辑，不应作为业务权限判断；发布版的用户权限必须依靠真正的身份/权限数据。
