## React Native 文档适合谁

React Native（常简称 RN）让开发者用 React 和 JavaScript 构建 Android、iOS 应用。官方教程同时面向 React 新手、原生 iOS/Android 工程师和初学编程者，因此会解释平台概念。你已经会 React，可以把这里当作“React 知识迁移到原生应用”的入门路线。

开始前应熟悉 JavaScript 的函数、模块、对象、数组、异步等基础。RN 并不要求先成为 Android 或 iOS 专家；不过了解原生平台的 UI、权限、构建和应用生命周期会帮助排查更深层的问题。

## 可以先在浏览器体验

文档嵌入了 Expo Snack，这是能在浏览器中编辑和运行 RN 示例的在线环境。Snack 会显示应用的运行效果，并可预览不同平台；可以先把屏幕文字改成自己的内容，观察代码变化怎样反映到视图上。文档也允许把代码放进本机的 RN 工程运行。网页浏览器里的移动端模拟器和真实 Android/iOS 设备不是一回事，后续需要设置本地开发环境时按 RN 环境指南操作。

下面是等价的最小组件示意，用来认识后文的 `Text` 组件；它不是该页面原样提供的 Snack 源码：

```tsx
import { Text } from 'react-native';

export default function App() {
  return <Text>你好，移动应用</Text>;
}
```

`Text` 是 RN 提供的文本组件。不同于网页直接在 `div` 中放文本，RN 要将可见文本放进适当的原生 UI 组件中。

## 文档中的平台提示

RN 文档会在需要时标注 Android、iOS 或 Web 开发者熟悉的内容。平台提示是为解释某个平台上的术语，不表示同一个 RN API 在所有平台上的细节完全相同。若说明中出现 IDE 菜单路径，例如 `Android Studio > Preferences`，粗体文字和 `>` 表示依次打开对应菜单。
