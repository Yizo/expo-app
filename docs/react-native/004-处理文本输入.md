## `TextInput` 与 Web 表单的区别

`TextInput` 是原生文本输入组件。`onChangeText` 收到的是新的文本字符串；与 Web DOM 的 `onChange` 常拿到事件对象不同，RN 这里可以直接把回调参数写入 state。`onSubmitEditing` 在用户提交输入时触发（例如通过键盘的提交键）；它适合执行搜索、发送内容等动作。

输入框内容会随键盘交互持续变化，通常由 state 保存。把 state 通过 `value` 传回输入框，就形成受控输入：React 状态是当前值的来源，回调负责更新它。

```tsx
import { useState } from 'react';
import { Text, TextInput, View } from 'react-native';

export default function PhraseTranslator() {
  const [phrase, setPhrase] = useState('');
  const [submitted, setSubmitted] = useState('');

  const translated = phrase.trim()
    ? phrase.trim().split(/\s+/).map(() => '🍕').join(' ')
    : '输入一句话试试';

  return (
    <View style={{ gap: 12, padding: 20 }}>
      <TextInput
        value={phrase}
        placeholder="例如：早上好，世界"
        onChangeText={setPhrase}
        onSubmitEditing={() => setSubmitted(phrase)}
        returnKeyType="done"
      />
      <Text>转换结果：{translated}</Text>
      {submitted !== '' && <Text>你提交了：{submitted}</Text>}
    </View>
  );
}
```

该示例按空白把输入拆成若干单词，并把每个词映射成披萨符号，说明如何在 state 中保留变化的文本、在提交时执行额外动作。真实表单还可在输入过程中校验内容。更多受控输入原则可从本页链接的 React 表单资料继续学习；触摸、按钮等其他交互需看 React Native 的触摸处理指南。

## 页面要点

- 用 `onChangeText` 处理输入的即时变化。
- 用 `onSubmitEditing` 处理提交。
- 用 state 保存会变化的文本，并将其绑定到 `value`。
- 键盘行为和输入属性以 RN 的 `TextInput` API 为准；不要把浏览器 DOM 事件处理器照搬过来。
