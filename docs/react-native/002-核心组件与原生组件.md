## 从 Web 的 UI 到原生视图

在网页里，React 通常将组件树渲染成 DOM 元素；RN 则把组件描述交给平台渲染成 iOS/Android 的原生视图。**视图（view）** 是屏幕上的 UI 单元，可以展示文字、图片、响应操作，也可以包含其他视图。按钮、文本行、容器等都可以由多个视图组成。

**原生组件（Native Component）** 指由平台 UI 能力支持的组件。RN 用 JavaScript/React API 描述它们，运行时创建对应平台的视图，因此它们不是网页 DOM 标签的改名版本。RN 也允许开发者为特定需求实现自定义原生组件，或使用社区组件；这通常涉及 Android/iOS 原生代码和 JS 边界。

> 当前官方页面提示：它引用的一部分 API 文档仍属于旧 API 集，尚待更新以反映新架构。阅读涉及原生模块或自定义原生组件的深入指南时，应确认适用的架构和 RN 版本。

## 常见核心组件

**核心组件（Core Components）** 是 RN 自带、可以直接用来搭 UI 的基础组件。下表按职责理解，不意味着 Web 和 RN 的行为完全相同。

| RN 组件 | 常见用途 | Web 中较接近的概念 |
|---|---|---|
| `View` | 布局容器；可嵌套子组件并参与触摸与无障碍处理 | 不滚动的 `div` |
| `Text` | 显示、嵌套和设置文本样式，也可承载文本交互 | `p` / 行内文本 |
| `Image` | 显示本地或远程图片资源 | `img` |
| `ScrollView` | 让一组子内容可以滚动 | 可滚动的 `div` |
| `TextInput` | 接受用户文本输入 | `input` / `textarea` |

以下重写示例将这些组件组合起来。它展示组件角色，不是官方表格附带的原代码：

```tsx
import { Image, ScrollView, Text, TextInput, View } from 'react-native';

export default function ProfilePanel() {
  return (
    <ScrollView contentContainerStyle={{ padding: 20 }}>
      <View style={{ gap: 12 }}>
        <Image
          source={{ uri: 'https://example.com/avatar.png' }}
          style={{ width: 72, height: 72, borderRadius: 36 }}
          accessibilityLabel="个人头像"
        />
        <Text>欢迎回来</Text>
        <TextInput placeholder="写一句状态" />
      </View>
    </ScrollView>
  );
}
```

区别要点：RN 常用 `style` 接收 JavaScript 对象；文字应放在 `Text` 中；资源的写法取决于是打包内的静态图片还是网络地址。`ScrollView` 适合内容规模有限且整体滚动的场景；大量数据应进一步学习虚拟化列表。
