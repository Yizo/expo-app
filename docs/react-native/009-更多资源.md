## 接下来可以学习什么

官方建议在了解基础组件后继续处理开发环境、开发工作流、UI 布局、调试、跨平台和社区参与等主题。遇到 JS/React 概念可以回看 React 和 MDN 文档；原生平台 API 则分别查 Android 与 Apple 文档。

## 工具和生态

页面推荐 VS Code 与 React Native 工具扩展，也建议浏览官方 showcase 和示例应用，了解组件组合与应用结构。React Native Directory 可查找社区提供的库和原生组件；原生开发指南介绍如何制作并分享 Native Components 与模块。

### Expo 和 Ignite

该官方 RN 页面将 Expo 描述为建立在 React Native 上的框架和开发工具服务：提供基于文件的路由、常用原生模块和开发工作流，也允许开发者在需要时接触 Xcode、Android Studio。页面还提到 Ignite 作为带有预设技术选型的起步模板。二者是独立生态工具，这份笔记不代替它们自己的文档。

页面提醒：其中一部分 Native Component / Module 链接引用旧 API 集，仍需更新以反映新架构。实现自定义原生能力时应进入对应版本的原生模块指南，不要把本学习路线里的旧代码当作当前实现蓝图。
