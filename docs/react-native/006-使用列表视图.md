## `FlatList`：同类长列表

列表通常会动态增长或变化。`FlatList` 针对可滚动的同构列表做了虚拟化：它主要渲染当前视口附近需要显示的项目，而不是像 `ScrollView` 那样把所有数据行同时渲染。数据集很大时这会节省内存和原生视图工作量。

两个核心 props 是：

- `data`：待展示的数据数组。
- `renderItem`：接收列表行信息并返回该行 UI 的函数。

```tsx
import { FlatList, Text, View } from 'react-native';

const people = [
  { id: 'p-1', name: '林然' },
  { id: 'p-2', name: '周宁' },
  { id: 'p-3', name: '何青' },
];

export default function PeopleList() {
  return (
    <FlatList
      data={people}
      keyExtractor={person => person.id}
      renderItem={({ item }) => (
        <View style={{ padding: 16 }}>
          <Text>{item.name}</Text>
        </View>
      )}
    />
  );
}
```

`keyExtractor` 在此为每一行提供稳定唯一的 key，便于 React 在数据变化时识别行。示例数据是硬编码的；实际页面常把服务器响应转换成数组后交给 `data`。网络请求是单独主题，不属于这个 Next 链页面的代码范围。

## `SectionList`：分组列表

当数据分成有标题的逻辑分组时，使用 `SectionList`。每组包含标题和该组的数据；行 UI 仍由 `renderItem` 创建，组标题由 `renderSectionHeader` 显示。

```tsx
import { SectionList, Text, View } from 'react-native';

const groups = [
  { title: '常用', data: ['消息', '联系人'] },
  { title: '工具', data: ['收藏', '设置'] },
];

export function GroupedMenu() {
  return (
    <SectionList
      sections={groups}
      keyExtractor={(entry, index) => `${entry}-${index}`}
      renderSectionHeader={({ section }) => <Text>{section.title}</Text>}
      renderItem={({ item }) => (
        <View style={{ padding: 12 }}><Text>{item}</Text></View>
      )}
    />
  );
}
```

简单记忆：少量静态的混排内容可用 `ScrollView`；大量同结构行用 `FlatList`；数据按区块分组则用 `SectionList`。
